# Security Policy

## Supported versions

Only the version currently deployed at [ifcvieweronline.eu](https://www.ifcvieweronline.eu) and the `main` branch receive security fixes.

## Reporting a vulnerability

Please **do not** open a public issue.

- Preferred: use GitHub's [private vulnerability reporting](../../security/advisories/new).
- Or email **privacy@ifcvieweronline.eu** with "SECURITY" in the subject.

Include steps to reproduce, the affected URL or component, and the impact you expect. You will get an acknowledgement within a few days. Please give us reasonable time to fix the issue before disclosing it publicly.

IFC files opened in the viewer are processed locally in your browser; reports about data leaving the browser unexpectedly are especially welcome.
