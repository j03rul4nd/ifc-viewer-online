# T-322v — Ship one theme app extension with all 20 blocks

## Objetivo
`shopify app deploy` (2026-11-23) failed: an app may have only ONE theme app extension
("maximum number of 1 module allowed for this extension type", once per uid). Put the
20 blocks back in `ifc-viewer`, inside Shopify's limits (100 KB Liquid total, 15 KB per
locale file, 30 blocks), and fix the deploy errors and warnings.

## ADR D-322v (supersedes D-322u)
- **Decision:** one theme app extension, `app/extensions/ifc-viewer`, generated by
  `integrations/shopify/build-extension.mjs` from readable sources in
  `integrations/shopify/blocks/` and `snippets/` (plus the two copy-paste sections).
- **Why:** Shopify allows a single theme app extension per app; the three-extension split
  of D-322u cannot deploy. Limits (shopify.dev, theme-app-extensions/configuration):
  10 MB total, 30 blocks, 100 locale files, 15 KB per locale file, 100 KB Liquid across
  all files (enforced); CSS 100 KB and JS 10 KB compressed per schema reference (suggested).
- **How it fits:**
  - Compact Liquid: comments (`{% comment %}` and `comment` inside `{% liquid %}`) removed,
    schema JSON minified, lines trimmed, blank lines dropped.
  - Short theme-editor keys: `t:settings.long_name` → `t:k.<FNV-1a base36, 4+ chars>`, stable
    per key; schema locales are written as `{ "k": { … } }`.
  - Script-only storefront texts (the old `*_labels` captures) moved to
    `assets/ifcvo-i18n-<lang>.json`, loaded with top-level await by `assets/ifcvo-i18n.js`,
    imported by each block script; the Liquid marks `data-i18n="<group>"`. Groups in
    `i18n-groups.json`. Server-rendered no-JS markup, JSON-LD and noscript keep their `| t`.
  - Stylesheet via schema `"stylesheet": "ifcvo.css"`; DPP checklist rows via snippet
    `ifcvo-dpp-item`.
  - A schema locale over 15 KB is left out (editor falls back to English): ja, th.
    A storefront locale or English over the limit is a build error.
- **Trade-offs:** generated files are not hand-editable; shopping texts the scripts use
  arrive one fetch later (English defaults until then, or if the fetch fails); Japanese
  and Thai merchants see English settings in the theme editor.
- **Margin:** 96,085 bytes of Liquid (limit checked at 100,000); next blocks must stay lean.

## Fixes from the deploy log
- `LiquidSyntaxError Unknown tag '''` (ifc-compat): multi-line string `join: '\n'` inside
  `{% liquid %}` → `join: '<br />'`.
- `ImgWidthAndHeight` (ifcvo-noscript): `image_url | image_tag` writes width and height.
- `L` naming → `shop_l`; unused `l_files`, `t_files`, `t_health` removed.
- Extension uid: kept `05442f2f-…` (the CLI could not be logged in here to read the
  registered uid). See Informe.
