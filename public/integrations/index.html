WordPress plugin

Available Free

What it does

A block and an [ifc_viewer] shortcode that show an interactive 3D IFC model in posts and pages.

Who it is for

Architects, engineers and manufacturers who publish projects or products on a WordPress site.

Install
  1. In WordPress, open Plugins → Add New.
  2. Search “Bimo IFC Viewer”, install and activate it.
  3. Add the IFC Viewer block, or paste [ifc_viewer model="…"], with a public IFC URL.
Limits

The IFC must be reachable by URL (media library or a public link). Very large models load slowly on phones.

Get it on wordpress.org

Shopify app

In review

What it does

An IFC model per product or variant, a specification table read from the model and file downloads on the product page.

Who it is for

Building-product manufacturers that sell or list products on Shopify.

Install
  1. Install the app from the Shopify App Store once it is approved.
  2. Attach an IFC file to a product or variant.
  3. Add the viewer block to the product template in the theme editor.
Limits

The app was submitted to the Shopify App Store and is in review, so it cannot be installed yet. Plans: Free, Starter and Business. Today you can copy the free theme sections from GitHub.

JavaScript SDK

Available Free

What it does

Mount the viewer in your own web app and load IFC bytes from your code, with events and an API for selection, colours and camera.

Who it is for

Developers of CDEs, portals and internal tools.

Install
  1. Import the SDK module from /sdk/ifc-viewer.es.js.
  2. Create the viewer on an element of your page.
  3. Pass the IFC bytes from your app with viewer.add().
Limits

Runs in the browser only: you need a page to host it. The SDK does not store files for you.

Embed (iframe)

Available Free

What it does

Paste one iframe to show a model on any page, with the camera, colours and panels you choose in the embed builder.

Who it is for

Anyone with a website, blog or CMS who does not want to write code.

Install
  1. Open the embed builder.
  2. Paste a public IFC URL and set the view.
  3. Copy the iframe into your page.
Limits

The model URL must allow cross-origin requests (CORS). The iframe needs about 400 px of height to be usable.

Local server for desktop tools (MCP)

Available Free

What it does

A local server that lets desktop apps and code editors that speak the Model Context Protocol validate IFC files, check IDS and open models in 3D.

Who it is for

BIM coordinators and developers who work with IFC files from desktop tools.

Install
  1. Install Node.js 18 or newer.
  2. Add “npx -y ifc-viewer-mcp” as a server in your tool’s MCP settings.
  3. Restart the tool and point it at an IFC file on your disk.
Limits

Needs a desktop tool that supports MCP and Node.js. Validation runs on your machine; the 3D view opens in the browser.
