Questions

What is an AGV digital twin?

A live 3D model of a warehouse where each automated guided vehicle, rack and dock is shown with its current state: where it is, its battery, what it is carrying and which order it serves.

Is the data in the demo real?

No. The fleet in the demo is a seeded simulation, marked as such, so it runs without anyone’s private data. A real deployment reads the fleet manager or the vehicles’ own feed.

Can it connect to my ERP or WMS?

Yes. Order status can flow both ways: orders in from the ERP, delivery confirmations out to Odoo, Salesforce or a WMS. Each integration is set up with the client.
