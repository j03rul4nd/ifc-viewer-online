IFC VIEWER SDK · v1.6.0

Integra il viewer nel tuo prodotto

Inserisci lo stesso viewer del browser nel tuo CDE, digital twin o strumenti interni di progetto. Carica dati IFC dalla tua app mentre l'elaborazione del modello resta nel client.

  • ✓ Nessun backend di caricamento
  • ✓ Funziona direttamente nel browser
  • ✓ Pronto per IFC, BCF e IDS

Avvio rapido

<div id="viewer" style="height:520px"></div>
<script type="module">
  import { IfcViewer } from "../ifc-viewer.es.js";

  const viewer = new IfcViewer("#viewer");

  const bytes = await fetch("/models/project.ifc").then(r => r.arrayBuffer());
  await viewer.add("project.ifc", bytes);
</script>

Oppure, senza JS — il tag:

<script type="module" src="../ifc-viewer.es.js"></script>
<ifc-viewer model="https://host/project.ifc" ui="minimal"
            style="display:block;height:520px"></ifc-viewer>

Il SDK individua l'URL dell'app rispetto a questo script, quindi l'auto-hosting funziona subito.

API

MetodoDescrizione
new IfcViewer(target, options?)Monta in un selettore CSS o elemento. Opzioni: ui, validate, panel, lang, height, model, loadTimeout, baseUrl.
add(name, bytes)Carica byte IFC (ArrayBuffer/Uint8Array) dalla tua app. Restituisce una promise con le info del modello.
addFromUrl(url, name?)Carica un URL IFC pubblico con CORS.
select(expressId)Seleziona e inquadra un elemento tramite l'expressID IFC.
isolate(ifcType?)Isola una categoria (es. "IfcWall"); ometti per azzerare.
setView(view)Vola a una vista camera: iso, top, front, right, left, back, bottom.
fit() · reset()Inquadra il modello attivo / reimposta la camera.
showAll()Ripristina la piena visibilità (rimuovi nascosti + isolamento).
setLanguage(lang)Cambia la lingua dell'interfaccia a runtime.
clear()Rimuovi tutti i modelli caricati.
getLanguages()Elenca i codici lingua supportati (etichette in IfcViewer.LANGUAGES).
getModels()Elenca i modelli caricati ({ id, fileName, elementCount }). Restituisce una promise.
getElement(id, modelId?)Recupera i dati IFC di un elemento (attributi + property/quantity set). Restituisce una promise.
getValidation()Recupera il riepilogo di validazione (Health Score + conteggi). Restituisce una promise.
getStats()Conteggio elementi per categoria e modello — per i grafici. Restituisce una promise.
getIssues(opts?)Problemi di validazione per una tabella (filtra per gravità / limite). Restituisce una promise.
checkIds(idsXml)Check the model against a buildingSMART IDS (.ids XML). Returns pass/fail per spec.
screenshot()Cattura la vista 3D corrente come data URL PNG. Restituisce una promise.
removeModel(modelId)Scarica un modello per id.
hideElements(ids) · showElements(ids)Nasconde / mostra un insieme di elementi per expressID.
setCamera(pos, dir)Posiziona la camera in una posizione guardando in una direzione.
on(event, cb)Iscriviti / annulla agli eventi; restituisce una funzione di annullamento.
dispose()Smonta e rimuovi l'iframe.

Eventi

MetodoDescrizione
readyViewer montato e pronto ({ languages }).
model-progressAvanzamento del caricamento ({ percent, phase }).
model-loadedUn modello ha finito di caricare ({ modelId, fileName, elementCount }).
validation-completedValidazione completata — Health Score ({ qualityScore, errors, warnings, info }).
model-errorUn caricamento è fallito ({ message }).
element-selectedL'utente ha scelto un elemento ({ expressId, ifcType, name }).

Il modello viene scaricato nel browser del visitatore e analizzato lato client con WebAssembly — nulla viene caricato sui nostri server.
