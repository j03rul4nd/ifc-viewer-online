IFC VIEWER SDK · v1.6.0

Integra el visor en tu propio producto

Inserta el mismo visor del navegador en tu CDE, gemelo digital o herramientas internas de proyecto. Carga datos IFC desde tu app mientras el procesamiento del modelo permanece en el cliente.

  • ✓ Sin backend de subida
  • ✓ Se ejecuta directamente en el navegador
  • ✓ Preparado para IFC, BCF e IDS

Inicio rápido

<div id="viewer" style="height:520px"></div>
<script type="module">
  import { IfcViewer } from "../ifc-viewer.es.js";

  const viewer = new IfcViewer("#viewer");

  const bytes = await fetch("/models/project.ifc").then(r => r.arrayBuffer());
  await viewer.add("project.ifc", bytes);
</script>

O, sin JS — usa la etiqueta:

<script type="module" src="../ifc-viewer.es.js"></script>
<ifc-viewer model="https://host/project.ifc" ui="minimal"
            style="display:block;height:520px"></ifc-viewer>

El SDK descubre la URL de la app de forma relativa a este script, así que el auto-alojamiento funciona sin más.

API

MétodoDescripción
new IfcViewer(target, options?)Monta en un selector CSS o elemento. Opciones: ui, validate, panel, lang, height, model, loadTimeout, baseUrl.
add(name, bytes)Carga bytes IFC (ArrayBuffer/Uint8Array) desde tu app. Devuelve una promesa con la info del modelo.
addFromUrl(url, name?)Carga una URL IFC pública con CORS habilitado.
select(expressId)Selecciona y encuadra un elemento por su expressID IFC.
isolate(ifcType?)Aísla una categoría (p. ej. "IfcWall"); omítelo para limpiar.
setView(view)Vuela a una vista de cámara: iso, top, front, right, left, back, bottom.
fit() · reset()Encuadra el modelo activo / reinicia la cámara.
showAll()Restaura toda la visibilidad (quita ocultos y aislamiento).
setLanguage(lang)Cambia el idioma de la interfaz en tiempo de ejecución.
clear()Elimina todos los modelos cargados.
getLanguages()Lista los códigos de idioma soportados (ver IfcViewer.LANGUAGES para etiquetas).
getModels()Lista los modelos cargados ({ id, fileName, elementCount }). Devuelve una promesa.
getElement(id, modelId?)Obtiene los datos IFC de un elemento (atributos + property/quantity sets). Devuelve una promesa.
getValidation()Obtiene el resumen de validación (Health Score + conteos). Devuelve una promesa.
getStats()Conteo de elementos por categoría y modelo — para gráficos de dashboard. Devuelve una promesa.
getIssues(opts?)Incidencias de validación para una tabla (filtra por severidad / límite). Devuelve una promesa.
checkIds(idsXml)Comprueba el modelo contra un IDS de buildingSMART (.ids XML). Devuelve pass/fail por spec.
screenshot()Captura la vista 3D actual como data URL PNG. Devuelve una promesa.
removeModel(modelId)Descarga un modelo por id.
hideElements(ids) · showElements(ids)Oculta / muestra un conjunto de elementos por expressID.
setCamera(pos, dir)Coloca la cámara en una posición mirando en una dirección.
on(event, cb)Suscríbete / cancela eventos; devuelve una función para desuscribir.
dispose()Desmonta y elimina el iframe.

Eventos

MétodoDescripción
readyVisor montado y listo ({ languages }).
model-progressProgreso de carga ({ percent, phase }).
model-loadedUn modelo terminó de cargar ({ modelId, fileName, elementCount }).
validation-completedValidación terminada — Health Score ({ qualityScore, errors, warnings, info }).
model-errorFalló una carga ({ message }).
element-selectedEl usuario seleccionó un elemento ({ expressId, ifcType, name }).

El modelo se descarga en el navegador del visitante y se parsea en el cliente con WebAssembly — no se sube nada a nuestros servidores.
