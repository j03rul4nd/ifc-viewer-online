IFC VIEWER SDK · v1.6.0

ビューアを自社プロダクトに組み込む

同じブラウザビューアを CDE、デジタルツイン、社内のプロジェクトツールに組み込みます。モデル処理はクライアント側のまま、自社アプリから IFC データを直接読み込みます。

  • ✓ アップロード用バックエンド不要
  • ✓ ブラウザ上で直接動作
  • ✓ IFC・BCF・IDS に対応

クイックスタート

<div id="viewer" style="height:520px"></div>
<script type="module">
  import { IfcViewer } from "../ifc-viewer.es.js";

  const viewer = new IfcViewer("#viewer");

  const bytes = await fetch("/models/project.ifc").then(r => r.arrayBuffer());
  await viewer.add("project.ifc", bytes);
</script>

または、JS なしでタグを：

<script type="module" src="../ifc-viewer.es.js"></script>
<ifc-viewer model="https://host/project.ifc" ui="minimal"
            style="display:block;height:520px"></ifc-viewer>

SDK はこのスクリプトからの相対でアプリ URL を自動検出するため、セルフホストはそのまま動作します。

ライブデモ

このページ自体が SDK を使用しています。クリックするとサンプル IFC を取得し、そのバイトをビューアに渡します。

API

メソッド説明
new IfcViewer(target, options?)CSS セレクタまたは要素にマウント。オプション: ui, validate, panel, lang, height, model, loadTimeout, baseUrl。
add(name, bytes)自社アプリから IFC バイト（ArrayBuffer/Uint8Array）を読み込みます。モデル情報を含む Promise を返します。
addFromUrl(url, name?)CORS 対応の公開 IFC URL を読み込みます。
select(expressId)IFC expressID で要素を選択してフレーミングします。
isolate(ifcType?)カテゴリを分離（例: "IfcWall"）。省略でクリア。
setView(view)カメラビューへ移動: iso, top, front, right, left, back, bottom。
fit() · reset()アクティブなモデルにフィット / カメラをリセット。
showAll()表示を全復元（非表示・分離を解除）。
setLanguage(lang)実行時に UI 言語を変更します。
clear()読み込み済みのモデルをすべて削除します。
getLanguages()対応言語コードを列挙（ラベルは IfcViewer.LANGUAGES）。
getModels()読み込み済みモデルを列挙（{ id, fileName, elementCount }）。Promise を返します。
getElement(id, modelId?)要素の IFC データ（属性＋プロパティ/数量セット）を取得。Promise を返します。
getValidation()現在の検証サマリ（ヘルススコア＋件数）を取得。Promise を返します。
getStats()モデルごとのカテゴリ別要素数 — ダッシュボードのグラフ用。Promise を返します。
getIssues(opts?)テーブル用の検証問題（重大度 / 件数でフィルタ）。Promise を返します。
checkIds(idsXml)Check the model against a buildingSMART IDS (.ids XML). Returns pass/fail per spec.
screenshot()現在の 3D ビューを PNG data URL として取得。Promise を返します。
removeModel(modelId)id でモデルをアンロードします。
hideElements(ids) · showElements(ids)expressID で要素の集合を非表示 / 表示します。
setCamera(pos, dir)カメラを指定位置に置き、指定方向を向かせます。
on(event, cb)イベントを購読 / 解除。解除用の関数を返します。
dispose()破棄して iframe を削除します。

イベント

メソッド説明
readyビューアがマウントされ準備完了（{ languages }）。
model-progress読み込みの進捗（{ percent, phase }）。
model-loadedモデルの読み込みが完了（{ modelId, fileName, elementCount }）。
validation-completed検証完了 — ヘルススコア（{ qualityScore, errors, warnings, info }）。
model-error読み込みに失敗（{ message }）。
element-selectedユーザーが要素を選択（{ expressId, ifcType, name }）。

モデルは訪問者のブラウザで取得され、WebAssembly によりクライアント側で解析されます — 当社サーバーには何もアップロードされません。
