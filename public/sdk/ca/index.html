IFC VIEWER SDK · v1.6.0

Integra el visor al teu propi producte

Insereix el mateix visor del navegador al teu CDE, bessó digital o eines internes de projecte. Carrega dades IFC des de la teva app mentre el processament del model es manté al client.

  • ✓ Sense backend de pujada
  • ✓ S'executa directament al navegador
  • ✓ Preparat per a IFC, BCF i IDS

Inici ràpid

<div id="viewer" style="height:520px"></div>
<script type="module">
  import { IfcViewer } from "../ifc-viewer.es.js";

  const viewer = new IfcViewer("#viewer");

  const bytes = await fetch("/models/project.ifc").then(r => r.arrayBuffer());
  await viewer.add("project.ifc", bytes);
</script>

O, sense JS — l’etiqueta:

<script type="module" src="../ifc-viewer.es.js"></script>
<ifc-viewer model="https://host/project.ifc" ui="minimal"
            style="display:block;height:520px"></ifc-viewer>

El SDK descobreix l'URL de l'app de manera relativa a aquest script, així que l'auto-allotjament funciona sol.

API

MètodeDescripció
new IfcViewer(target, options?)Munta en un selector CSS o element. Opcions: ui, validate, panel, lang, height, model, loadTimeout, baseUrl.
add(name, bytes)Carrega bytes IFC (ArrayBuffer/Uint8Array) des de la teva app. Retorna una promesa amb la info del model.
addFromUrl(url, name?)Carrega un URL IFC públic amb CORS.
select(expressId)Selecciona i enquadra un element pel seu expressID IFC.
isolate(ifcType?)Aïlla una categoria (p. ex. "IfcWall"); omet-ho per netejar.
setView(view)Vola a una vista de càmera: iso, top, front, right, left, back, bottom.
fit() · reset()Enquadra el model actiu / reinicia la càmera.
showAll()Restaura tota la visibilitat (treu ocults + aïllament).
setLanguage(lang)Canvia l'idioma de la interfície en temps d'execució.
clear()Elimina tots els models carregats.
getLanguages()Llista els codis d'idioma admesos (etiquetes a IfcViewer.LANGUAGES).
getModels()Llista els models carregats ({ id, fileName, elementCount }). Retorna una promesa.
getElement(id, modelId?)Obté les dades IFC d'un element (atributs + property/quantity sets). Retorna una promesa.
getValidation()Obté el resum de validació (Health Score + recomptes). Retorna una promesa.
getStats()Recompte d’elements per categoria i model — per a gràfics. Retorna una promesa.
getIssues(opts?)Incidències de validació per a una taula (filtra per severitat / límit). Retorna una promesa.
checkIds(idsXml)Check the model against a buildingSMART IDS (.ids XML). Returns pass/fail per spec.
screenshot()Captura la vista 3D actual com a data URL PNG. Retorna una promesa.
removeModel(modelId)Descarrega un model per id.
hideElements(ids) · showElements(ids)Amaga / mostra un conjunt d'elements per expressID.
setCamera(pos, dir)Col·loca la càmera en una posició mirant en una direcció.
on(event, cb)Subscriu-te / cancel·la esdeveniments; retorna una funció per cancel·lar.
dispose()Desmunta i elimina l'iframe.

Esdeveniments

MètodeDescripció
readyVisor muntat i a punt ({ languages }).
model-progressProgrés de càrrega ({ percent, phase }).
model-loadedUn model ha acabat de carregar ({ modelId, fileName, elementCount }).
validation-completedValidació acabada — Health Score ({ qualityScore, errors, warnings, info }).
model-errorUna càrrega ha fallat ({ message }).
element-selectedL'usuari ha triat un element ({ expressId, ifcType, name }).

El model es baixa al navegador del visitant i s'analitza al client amb WebAssembly — no es puja res als nostres servidors.
