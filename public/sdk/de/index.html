IFC Viewer SDK · v1.16.0

Binde den IFC-Viewer in dein eigenes Produkt ein

Füge denselben Browser-Viewer in dein CDE, deinen digitalen Zwilling oder interne Projekt-Tools ein. Lade IFC-Daten direkt aus deiner App, während jedes Modell im Client geparst wird.

Einrichtung

#Schnellstart

Wähle deinen Stack. Kopieren, einfügen, rendern — ohne Build-Schritt, ohne API-Key.

Null JavaScript — Tag in eine beliebige Seite oder ein Dashboard setzen und Attribute vergeben.

Im Effect mounten, beim Unmount abbauen. Sicher bei der doppelten Ausführung im StrictMode von React 18.

In onMounted mounten, in onUnmounted aufräumen.

Gehostet oder selbst gehostet

Die Snippets importieren von unserem CDN, das auf jedem Origin funktioniert. Zum Selbsthosten lieferst du ifc-viewer.es.js von deiner eigenen Domain aus — das SDK ermittelt die App-URL relativ zum Skript. Läuft die App woanders? Setze die Option baseUrl.

Noch kein npm-Paket: Modul per URL importieren (oben) oder ifc-viewer.es.js in deine App übernehmen.

Architektur

#So funktioniert es

Ein winziger Wrapper in deiner Seite, der vollständige Viewer in einem isolierten iframe, deine Bytes dazwischen übertragen — und dort verarbeitet, wo sie ohnehin liegen.

Deine App

Ein ES-Modul von ~6 KB, das ein iframe und eine typisierte JS-API erzeugt. Nichts vom schweren 3D- und Parsing-Gewicht landet in deinem Bundle.

postMessage-Brücke

IFC-Bytes werden als ArrayBuffer an das iframe übertragen (ohne Kopie). Befehle und Abfragen sind korrelierte Request/Response-Nachrichten.

Der Viewer

three.js + web-ifc, zu WebAssembly kompiliert, parsen und rendern das Modell im iframe — auf dem Rechner der Besucherin oder des Besuchers.

Warum es privat ist

Modelle erreichen nie einen Server. Keine Upload-Pipeline abzusichern, keine Frage der Datenresidenz, keine Warteschlange nach Dateigröße.

Warum es skaliert

Die Berechnung läuft auf dem Gerät der jeweiligen Besucher. Ein 200-MB-Modell auszuliefern kostet dasselbe wie ein 2-MB-Modell — es ist eine statische Datei.

Konzepte

#Kernkonzepte

Vier Dinge, die man vor dem Bauen wissen sollte.

Mounten & Bereitschaft

new IfcViewer(target) mountet sofort und stellt Befehle in eine Warteschlange, bis der Viewer bereit ist. await IfcViewer.create(target) (oder whenReady()) liefert eine Instanz, die du direkt verwenden kannst.

Bytes oder URL

add(name, bytes) überträgt Bytes, die du bereits hast — kein CORS, nichts hochgeladen; der Buffer wird transferiert (detached), gib also eine Kopie mit, wenn du ihn noch brauchst. addFromUrl(url) lädt stattdessen eine öffentliche URL mit CORS.

Events

Mit on(event, cb) abonnieren, das eine Funktion zum Abbestellen zurückgibt. Verfügbar sind ready, model-progress, model-loaded, validation-completed, model-error und element-selected.

Abfragen

Daten bei Bedarf abrufen: getModels, getElement, getValidation, getStats, getIssues, checkIds, checkEir, screenshot. Jede ist Request/Response und wird nach einem Timeout abgelehnt (30 s; IDS / EIR bis 120 s).

#API-Referenz

Jede Methode, gruppiert — mit Signaturen und Rückgabetypen. Danach folgen Konstruktor-Optionen, Events und die Web Component <ifc-viewer>.

Konstruktor

In einen CSS-Selektor oder ein Element einhängen. Siehe die Optionen unten.

Erzeugt einen Viewer und löst auf, sobald er Befehle annehmen kann.

Modelle laden

IFC-Bytes (ArrayBuffer/Uint8Array) aus deiner App laden. Der Buffer wird für eine kopierfreie Übergabe transferiert.

Kamera & Auswahl

select(expressId, modelId?)void

Ein Element per IFC-expressID auswählen und einrahmen.

Zu einer Kameraansicht fliegen: iso, top, front, right, left, back, bottom.

Ob der Begehungsmodus aktiv ist und mit welcher Geschwindigkeit.

Sichtbarkeit

Blendet eine Menge von Elementen per expressID aus / ein.

setModelVisible(modelId, visible)Promise<void>

Ein Modell einer föderierten Szene ein- oder ausblenden, ohne es zu entladen.

setModelOpacity(opacity, modelId?)Promise<void>

Ein Modell transparent machen (0,05–1) — z. B. die Architektur um die TGA.

Aussehen & Präsentation

Szenenhintergrund ändern: ein Preset ('white', 'paper', 'blueprint', 'sky', 'studio'), '#rrggbb', '#oben,#unten' oder { top, bottom }. Wird nicht als Präferenz des Besuchers gespeichert.

Der aktuelle Szenenhintergrund.

setAccent(color)Promise<void>

Akzentfarbe der Oberfläche zur Laufzeit ändern (#rrggbb).

setClientMode(enabled)Promise<void>

Kundenansicht ein- oder ausschalten — die Ansicht für Stakeholder, wie ui: 'client'.

setRenderQuality(quality)Promise<void>

'quality' schaltet das aufwendigere Rendering für ein Titelbild ein; 'standard' für den Alltag.

Sonnenstudie

Echte Schatten zu einem ortsüblichen Datum und einer Uhrzeit: { date: '06-21', time: '18:00' }. Der Standort kommt aus der IFC-Georeferenz; für ein Modell ohne sie location übergeben — nie stillschweigend eine Standardstadt.

getSolar()Promise<SolarState>

Datum, Uhrzeit und Zeitzone der Studie und wo der Standort liegt.

Kartenmodus

setSiteContext(opts?)Promise<SiteContextState>

Modell mit Gelände und OpenStreetMap-Umgebung auf die Karte setzen. Der Aufruf erklärt die Kachel-Einwilligung Ihrer Seite für ihre Besucher; zeigen Sie die Quellenangaben.

getSiteContext()Promise<SiteContextState>

Zustand des Kartenmodus, Platzierung und die anzuzeigenden Quellenangaben.

Schnitte

addSection({ axis?, offset?, level?, flip? })Promise<SectionsState & { id }>

Schnittebene hinzufügen. { level: 'EG' } ist ein Grundriss auf diesem Geschoss; { axis: 'x', offset: 4.5 } ein Schnitt bei 4,5 m.

updateSection(id, { offset?, enabled?, flipped? })Promise<SectionsState>

Ebene verschieben, ein-/ausschalten oder umkehren.

removeSection(id?)Promise<SectionsState>

Eine Ebene entfernen, oder alle Schnitte ohne id.

setSectionBox('model' | 'selection' | false)Promise<SectionsState>

Schnittbox um das Modell oder die Auswahl; false entfernt sie.

getSections()Promise<SectionsState>

Alle Ebenen, die Box und die Geschosse für Ebenenschnitte.

Touren

startTour(template?, { autoplay?, title? })Promise<TourState>

Eine vordefinierte Tour starten: 'social', 'client-walkthrough' oder 'technical-review' (geht die Validierungsbefunde durch). Abgespielt von der Tour-Leiste des Viewers.

playTour({ title?, steps }, { startAt?, autoplay? })Promise<TourState>

Eine eigene Tour abspielen: Kamerastopps mit Text, Hervorhebungen und isolierten Klassen. autoplay: true oder ms pro Stopp.

nextTourStep() · prevTourStep() · goToTourStep(i)Promise<TourState>

Zwischen Stopps wechseln.

setTourAutoplay(autoplay)Promise<TourState>

Automatisches Weiterschalten der laufenden Tour ein- oder ausschalten.

stopTour()Promise<TourState>

Tour beenden und die Kamera zurückgeben.

getTour()Promise<TourState>

Die Tour und ihre Stopps in der Form von playTour() — speichern und später erneut abspielen.

Präsentations-Regie

getPresentationRecipes()Promise<PresentationRecipe[]>

Die eingebauten Regie-Rezepte (Meeting-Demo, Reel, LinkedIn-Teaser, Launch, Editorial-Looks…).

createPresentation(recipe?, options?)Promise<PresentationState>

Das Modell per Rezept in ein geschnittenes Video verwandeln: Einstellungen aus dem IFC geplant, Texte, Musik. Öffnet Clip Studio mit dem Ergebnis. Fortschritt über presentation-progress.

Die Präsentation im Browser des Besuchers kodieren und die MP4-Bytes erhalten — hochladen, anhängen oder in einem <video> abspielen.

closePresentation()Promise<void>

Clip Studio schließen.

Cover-Studio

getCoverOptions()Promise<CoverCatalog>

Die Rezepte, Vorlagen, Formate und Paletten des Cover-Studios.

createCover({ recipe?, template?, format?, palette?, text? })Promise<CoverState>

Ein Cover erstellen: ein Rezept ausführen (es nimmt die nötigen Ansichten auf), dann Vorlage, Format, Palette und Texte setzen. Öffnet das Cover-Studio, weiter bearbeitbar.

getCover()Promise<CoverState | null>

Das Cover im aktuellen Stand, oder null, wenn das Studio geschlossen ist.

exportCover({ type?, slide? })Promise<CoverFile>

Exportieren: png / jpeg (eine Seite), pdf / pptx (das ganze Dokument), zip (alle Seiten). Liefert die Bytes.

closeCover()Promise<void>

Das Cover-Studio schließen.

Artikel-Kit

activate()void

Einen verzögerten Viewer jetzt starten (was der Poster-Button tut). Frühere Aufrufe warten in der Warteschlange.

bindSteps(steps, { rootMargin? })() => void

Scrollytelling: Während jeder Absatz die Bildschirmmitte kreuzt, wird eingepasst, isoliert, die Sonne bewegt oder Ihr Code ausgeführt. Liefert eine Funktion zum Lösen.

setTurntable(enabled | degPerSec)Promise<{ active, speed }>

Langsame Drehung im Leerlauf (Grad pro Sekunde; false stoppt). Stoppt bei der ersten Berührung, nie bei reduzierter Bewegung.

toggleFullscreen()Promise<void>

Die Abbildung auf Vollbild vergrößern oder zurück.

setPaused(paused)Promise<{ paused }>

Das Rendern anhalten oder fortsetzen. pauseOffscreen erledigt das für Sie.

Szenengruppen

getGroups()Promise<SceneGroupsState>

Alle Gruppen der Szene — aus dem IFC abgeleitet (Projekt, Grundstück, Standort) und von Nutzern angelegt.

createGroup(name, modelIds?)Promise<string>

Eine Gruppe anlegen, optional mit Modellen. Liefert ihre id.

renameGroup(id, name) · deleteGroup(id)Promise<void>

Eine Nutzergruppe umbenennen oder löschen. Automatische Gruppen sind nicht editierbar.

assignToGroup(itemId, groupId | null | 'loose')Promise<void>

Ein Modell oder eine Punktwolke in eine Gruppe verschieben; null gibt es der automatischen Gruppierung zurück, 'loose' lässt es ohne Gruppe.

setGroupVisible(id, visible) · isolateGroup(id | null)Promise<void>

Eine ganze Gruppe ein- oder ausblenden, oder nur eine zeigen.

frameGroup(id)Promise<void>

Die Kamera auf eine Gruppe ausrichten — ausgeblendete Mitglieder eingeschlossen.

Messungen

setMeasureTool(tool)Promise<void>

Messwerkzeug für den Besucher aktivieren (öffnet das Mess-Panel) oder 'none'. Ergebnisse kommen über measurements-changed.

getMeasurements()Promise<MeasurementsState>

Alle Messungen auf dem Bildschirm. Werte in SI — Meter, m², Grad — unabhängig von der Anzeige.

clearMeasurements(id?)Promise<MeasurementsState>

Eine Messung entfernen, oder alle.

Abfragen

getModels()Promise<ModelSummary[]>

Listet die geladenen Modelle. Gibt ein Promise zurück.

getElement(id, modelId?)Promise<IfcElementData | null>

Liefert die IFC-Daten eines Elements (Attribute + Property-/Quantity-Sets). Gibt ein Promise zurück.

getValidation()Promise<ValidationSummary | null>

Liefert die aktuelle Validierungs-Zusammenfassung (Health Score + Zähler). Gibt ein Promise zurück.

getStats()Promise<StatsResult>

Elementanzahl je Kategorie und Modell — für Dashboard-Diagramme. Gibt ein Promise zurück.

getIssues(opts?)Promise<IssuesResult>

Validierungsmeldungen für eine Tabelle (Filter nach Schweregrad / Limit). Gibt ein Promise zurück.

screenshot()Promise<string>

Erfasst die aktuelle 3D-Ansicht als PNG-Data-URL. Gibt ein Promise zurück.

compare({ base, head, baseLabel?, headLabel? })Promise<{ changes }>

Vergleicht zwei Lieferungen per URL (über die GlobalId) und öffnet die Vergleichsansicht mit dem Ergebnis.

Panels

openPanel(panel | null) · closePanel()void

Öffnet ein Werkzeug-Panel, oder null, um das geöffnete zu schließen. Ein nicht verfügbares Panel — vom Chrome ausgeblendet oder ohne geladene Daten — bleibt wirkungslos und ist kein Fehler.

getPanels()Promise<PanelsResult>

Welches Panel offen ist und welche gerade angeboten werden. Ein Werkzeug, das in `available` fehlt, lässt sich nicht öffnen; es ist nicht bloß deaktiviert.

setPanels(panels)void

Beschränkt die Leiste zur Laufzeit auf diese Panels. Gleiches Vokabular wie der URL-Parameter `panels=` und hat Vorrang davor. Schränkt das Angebot ein und erweitert es nie; ein leeres Array bedeutet keine Leiste.

Punktwolken

addPointCloud(fileName, bytes)Promise<string>

Lädt einen Scan aus Bytes — LAS, LAZ, COPC, PLY, PCD oder Text. Der Puffer wird übertragen, nicht kopiert. Liefert die Cloud-ID.

addPointCloudFromUrl(url, fileName?)Promise<string>

Lädt einen Scan, den der Viewer selbst abruft. Die URL muss CORS erlauben.

listPointClouds()Promise<PointCloudInfo[]>

Alle geladenen Scans. `pointCount` ist das Residente, `declaredCount` das, was die Datei enthält — sie unterscheiden sich, wenn das Budget den Parse abgeschnitten hat.

removePointCloud(cloudId) · clearPointClouds()Promise<void>

Entlädt einen Scan und gibt seine GPU-Puffer frei, oder entlädt alle.

setPointCloudVisible(cloudId, visible)Promise<void>

Blendet einen Scan ein oder aus, ohne ihn zu entladen.

fitPointCloud(cloudId?)Promise<void>

Rahmt die Kamera auf einen Scan, oder auf den zuerst geladenen.

setPointCloudDisplay(display, renderBudget?)Promise<void>

Punktgröße, Deckkraft, Farbmodus, Dichte, Konfidenzschwelle — für alle Scans gemeinsam. Jedes ist ein Shader-Uniform und damit auch bei 20 Millionen Punkten sofort wirksam.

inspectPointCloud(enabled?)Promise<void>

Aktiviert Klick-zum-Auslesen. Ein Klick auf einen Punkt sendet dann `pointcloud-picked` mit den Koordinaten AUS DER DATEI neben denen der Szene.

setPointCloudPlacement(placement, cloudId?)Promise<void>

Verschiebt einen Scan von Hand: Position, Gierung, Nivellierung, Maßstab. Partiell und begrenzt; wirkt auf die ermittelte Ausrichtung, ohne sie zu ersetzen.

setPointCloudUpAxis(axis, cloudId?)Promise<void>

Korrigiert, welche Achse der Scan als oben behandelt. PLY, PCD und Text geben keine Orientierung an, der Viewer leitet sie ab — prüfen Sie `upAxisSource`.

Imported 3D models

addMesh(files)Promise<string>

Importiert ein Modell aus Bytes. Erwartet eine LISTE: eine .gltf braucht ihre .bin und Texturen, eine .obj ihre .mtl — allein ergibt die Eingabedatei graue Geometrie.

addMeshFromUrl(urls)Promise<string>

Importiert ein Modell, das der Viewer abruft. Übergeben Sie alle nötigen URLs; sie werden parallel geladen und müssen alle CORS erlauben.

listMeshes()Promise<MeshInfo[]>

Alle importierten Modelle mit Dreiecks- und Texturzahlen. Lesen Sie `unitSource` und `upAxisSource`, bevor Sie den Werten daneben trauen.

removeMesh(meshId?) · clearMeshes()Promise<void>

Entfernt einen Import und gibt Geometrie, Materialien und Texturen frei, oder entfernt alle.

setMeshVisible(visible, meshId?)Promise<void>

Blendet einen Import ein oder aus, ohne ihn zu entladen.

fitMesh(meshId?)Promise<void>

Rahmt die Kamera auf einen Import, oder auf alle.

setMeshPlacement(placement, meshId?)Promise<void>

Platziert einen Import von Hand: Position, Gierung, Nivellierung, Maßstab. Partiell und begrenzt. Importe starten mittig über dem IFC, auf dessen Boden.

setMeshUpAxis(axis, meshId?)Promise<void>

Korrigiert die Hochachse der Quelle. Nur bei OBJ sinnvoll — die glTF-Spezifikation schreibt Y oben vor, daher meldet sie `upAxisSource: 'declared'`.

setMeshUnit(unitScale, meshId?)Promise<void>

Korrigiert die Quelleinheit: 1 Meter, 0,01 Zentimeter, 0,001 Millimeter, 0,3048 Fuß. Keines dieser Formate hält sie fest, der Viewer leitet sie aus der Modellgröße ab.

IDS- und EIR-Konformität

checkIds(idsXml)Promise<IdsResult>

Prüft das Modell gegen ein buildingSMART-IDS (.ids-XML). Läuft in einem Worker. Liefert bestanden/nicht bestanden je Spezifikation.

checkEir(profile)Promise<IdsResult>

Prüft das Modell gegen ein EIR- / BIM-Validierungsprofil (Objekt oder JSON, inkl. Kurzschreibweise). Wird zu IDS kompiliert und läuft auf derselben Engine — dieselbe IdsResult-Struktur wie checkIds.

Sprachen

getLanguages()string[]

#Fehlerbehebung

Die wenigen Dinge, über die man stolpert.

Es wird nichts gerendert

Prüfe der Reihe nach: ob der Viewer ready erreicht hat, ob das Modell geladen wurde (model-loaded statt model-error), ob der Container eine Höhe ungleich null hat und ob die Byte-Quelle gültiges IFC ist. Die Meldung von model-error nennt die Ursache.

Beim Laden eines Modells kommt ein CORS-Fehler

CORS betrifft nur addFromUrl(url). Wenn du die Bytes kontrollierst, lade sie selbst und rufe add(name, bytes) auf — CORS greift nicht, weil du die Daten direkt übergibst.

Das iframe bleibt leer oder lädt nicht

Die App muss einbettbar sein — kein X-Frame-Options: DENY und keine restriktive frame-ancestors-CSP auf dem Host. Unsere gehostete App erlaubt das Einbetten.

Mein ArrayBuffer ist nach add() leer

add() transferiert den Buffer für eine Übergabe ohne Kopie, wodurch er in deinem Code detached wird. Übergib eine Kopie (bytes.slice(0)), wenn du die Bytes danach noch brauchst.

Ladevorgänge oder Abfragen laufen in einen Timeout

add()/addFromUrl() werden nach loadTimeout abgelehnt (Standard 120 s; 0 deaktiviert). Abfragen nach 30 s, checkIds nach 120 s. Große Modelle auf langsamen Geräten brauchen eventuell ein höheres loadTimeout.

Welche Browser werden unterstützt?

Jeder moderne Evergreen-Browser mit WebAssembly und ES-Modulen — Chrome, Edge, Firefox, Safari. Kein Internet Explorer.

Auf meinem lokalen Dev-Server kommt ein 404

Ein SPA-Dev-Server kann /sdk/ mit seinem HTML-Fallback abfangen. Teste gegen einen echten Build oder ein statisches Hosting, oder importiere das Modul /sdk/ifc-viewer.es.js direkt.

Bette den IFC-Viewer überall ein. Im Browser verarbeitet, nie hochgeladen.

Das Modell wird im Browser des Besuchers geladen und clientseitig mit WebAssembly geparst — nichts wird auf unsere Server hochgeladen.
