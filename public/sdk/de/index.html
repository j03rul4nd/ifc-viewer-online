IFC VIEWER SDK · v1.6.0

Binde den Viewer in dein eigenes Produkt ein

Füge denselben Browser-Viewer in dein CDE, deinen digitalen Zwilling oder interne Projekt-Tools ein. Lade IFC-Daten direkt aus deiner App, während die Modellverarbeitung im Client bleibt.

  • ✓ Kein Upload-Backend nötig
  • ✓ Läuft direkt im Browser
  • ✓ Bereit für IFC, BCF & IDS

Schnellstart

<div id="viewer" style="height:520px"></div>
<script type="module">
  import { IfcViewer } from "../ifc-viewer.es.js";

  const viewer = new IfcViewer("#viewer");

  const bytes = await fetch("/models/project.ifc").then(r => r.arrayBuffer());
  await viewer.add("project.ifc", bytes);
</script>

Oder ganz ohne JS — das Tag:

<script type="module" src="../ifc-viewer.es.js"></script>
<ifc-viewer model="https://host/project.ifc" ui="minimal"
            style="display:block;height:520px"></ifc-viewer>

Das SDK ermittelt die App-URL relativ zu diesem Skript — Self-Hosting funktioniert ohne Konfiguration.

API

MethodeBeschreibung
new IfcViewer(target, options?)In einen CSS-Selektor oder ein Element einhängen. Optionen: ui, validate, panel, lang, height, model, loadTimeout, baseUrl.
add(name, bytes)IFC-Bytes (ArrayBuffer/Uint8Array) aus deiner App laden. Gibt ein Promise mit den Modellinfos zurück.
addFromUrl(url, name?)Eine öffentliche, CORS-fähige IFC-URL laden.
select(expressId)Ein Element per IFC-expressID auswählen und einrahmen.
isolate(ifcType?)Eine Kategorie isolieren (z. B. "IfcWall"); ohne Wert zum Zurücksetzen.
setView(view)Zu einer Kameraansicht fliegen: iso, top, front, right, left, back, bottom.
fit() · reset()Aktives Modell einpassen / Kamera zurücksetzen.
showAll()Volle Sichtbarkeit wiederherstellen (Ausgeblendetes + Isolation aufheben).
setLanguage(lang)Die UI-Sprache zur Laufzeit ändern.
clear()Alle geladenen Modelle entfernen.
getLanguages()Unterstützte Sprachcodes auflisten (Labels via IfcViewer.LANGUAGES).
getModels()Listet die geladenen Modelle ({ id, fileName, elementCount }). Gibt ein Promise zurück.
getElement(id, modelId?)Liefert die IFC-Daten eines Elements (Attribute + Property-/Quantity-Sets). Gibt ein Promise zurück.
getValidation()Liefert die aktuelle Validierungs-Zusammenfassung (Health Score + Zähler). Gibt ein Promise zurück.
getStats()Elementanzahl je Kategorie und Modell — für Dashboard-Diagramme. Gibt ein Promise zurück.
getIssues(opts?)Validierungsmeldungen für eine Tabelle (Filter nach Schweregrad / Limit). Gibt ein Promise zurück.
checkIds(idsXml)Check the model against a buildingSMART IDS (.ids XML). Returns pass/fail per spec.
screenshot()Erfasst die aktuelle 3D-Ansicht als PNG-Data-URL. Gibt ein Promise zurück.
removeModel(modelId)Entlädt ein Modell per id.
hideElements(ids) · showElements(ids)Blendet eine Menge von Elementen per expressID aus / ein.
setCamera(pos, dir)Positioniert die Kamera an einer Position mit Blickrichtung.
on(event, cb)Events abonnieren / abbestellen; gibt eine Abmelde-Funktion zurück.
dispose()Abbauen und das iframe entfernen.

Events

MethodeBeschreibung
readyViewer eingehängt und bereit ({ languages }).
model-progressLadefortschritt ({ percent, phase }).
model-loadedEin Modell wurde geladen ({ modelId, fileName, elementCount }).
validation-completedValidierung fertig — Health Score ({ qualityScore, errors, warnings, info }).
model-errorEin Laden ist fehlgeschlagen ({ message }).
element-selectedDer Nutzer hat ein Element gewählt ({ expressId, ifcType, name }).

Das Modell wird im Browser des Besuchers geladen und clientseitig mit WebAssembly geparst — nichts wird auf unsere Server hochgeladen.
