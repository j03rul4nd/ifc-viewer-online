IFC VIEWER SDK · v1.6.0

Embed the viewer in your own product

Insert the same browser viewer into your CDE, digital twin, or internal project tools. Load IFC data straight from your app while model processing stays on the client.

  • ✓ No upload backend required
  • ✓ Runs directly in the browser
  • ✓ Ready for IFC, BCF & IDS

Quick start

<div id="viewer" style="height:520px"></div>
<script type="module">
  import { IfcViewer } from "./ifc-viewer.es.js";

  const viewer = new IfcViewer("#viewer");

  const bytes = await fetch("/models/project.ifc").then(r => r.arrayBuffer());
  await viewer.add("project.ifc", bytes);
</script>

Or, zero-JS — drop the tag:

<script type="module" src="./ifc-viewer.es.js"></script>
<ifc-viewer model="https://host/project.ifc" ui="minimal"
            style="display:block;height:520px"></ifc-viewer>

The SDK auto-discovers the app URL relative to this script, so self-hosting just works.

API

MethodDescription
new IfcViewer(target, options?)Mount in a CSS selector or element. Options: ui, validate, panel, lang, height, model, loadTimeout, baseUrl.
add(name, bytes)Load IFC bytes (ArrayBuffer/Uint8Array) from your app. Returns a promise with the loaded model info.
addFromUrl(url, name?)Load a public, CORS-enabled IFC URL.
select(expressId)Select and frame an element by IFC expressID.
isolate(ifcType?)Isolate a category (e.g. "IfcWall"); omit to clear.
setView(view)Fly to a camera view: iso, top, front, right, left, back, bottom.
fit() · reset()Frame the active model / reset the camera.
showAll()Restore full visibility (clear hidden + isolation).
setLanguage(lang)Change the UI language at runtime.
clear()Remove all loaded models.
getLanguages()List the supported language codes (see IfcViewer.LANGUAGES for labels).
getModels()List the loaded models ({ id, fileName, elementCount }). Returns a promise.
getElement(id, modelId?)Fetch an element’s IFC data (attributes + property/quantity sets). Returns a promise.
getValidation()Fetch the current validation summary (Health Score + counts). Returns a promise.
getStats()Per-category element counts per model — for dashboard charts. Returns a promise.
getIssues(opts?)Validation issues for a table (filter by severity / limit). Returns a promise.
checkIds(idsXml)Check the model against a buildingSMART IDS (.ids XML). Returns pass/fail per spec.
screenshot()Capture the current 3D view as a PNG data URL. Returns a promise.
removeModel(modelId)Unload a model by id.
hideElements(ids) · showElements(ids)Hide / show a set of elements by expressID.
setCamera(pos, dir)Place the camera at a position looking along a direction.
on(event, cb)Subscribe / unsubscribe to events; returns an unsubscribe function.
dispose()Tear down and remove the iframe.

Events

MethodDescription
readyViewer mounted and ready ({ languages }).
model-progressLoad progress ({ percent, phase }).
model-loadedA model finished loading ({ modelId, fileName, elementCount }).
validation-completedValidation finished — Health Score ({ qualityScore, errors, warnings, info }).
model-errorA load failed ({ message }).
element-selectedThe user picked an element ({ expressId, ifcType, name }).

The model is fetched in the visitor's browser and parsed client-side with WebAssembly — nothing is uploaded to our servers.
