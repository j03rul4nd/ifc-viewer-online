IFC VIEWER SDK · v1.6.0

ฝังตัวแสดงผลลงในผลิตภัณฑ์ของคุณเอง

แทรกตัวแสดงผลบนเบราว์เซอร์เดียวกันลงใน CDE ดิจิทัลทวิน หรือเครื่องมือภายในของโครงการ โหลดข้อมูล IFC จากแอปของคุณ โดยการประมวลผลโมเดลยังคงอยู่ที่ฝั่งไคลเอนต์

  • ✓ ไม่ต้องมีแบ็กเอนด์อัปโหลด
  • ✓ ทำงานในเบราว์เซอร์โดยตรง
  • ✓ พร้อมสำหรับ IFC, BCF และ IDS

เริ่มต้นอย่างรวดเร็ว

<div id="viewer" style="height:520px"></div>
<script type="module">
  import { IfcViewer } from "../ifc-viewer.es.js";

  const viewer = new IfcViewer("#viewer");

  const bytes = await fetch("/models/project.ifc").then(r => r.arrayBuffer());
  await viewer.add("project.ifc", bytes);
</script>

หรือแบบไม่ต้องเขียน JS — ใช้แท็ก:

<script type="module" src="../ifc-viewer.es.js"></script>
<ifc-viewer model="https://host/project.ifc" ui="minimal"
            style="display:block;height:520px"></ifc-viewer>

SDK จะค้นหา URL ของแอปโดยอ้างอิงจากสคริปต์นี้ ดังนั้นการโฮสต์เองจึงใช้งานได้ทันที

เดโมสด

หน้านี้ใช้ SDK เอง คลิกเพื่อดึงไฟล์ IFC ตัวอย่างและส่งไบต์ไปยังตัวแสดงผล

ว่าง

API

เมธอดคำอธิบาย
new IfcViewer(target, options?)ติดตั้งในตัวเลือก CSS หรืออิลิเมนต์ ออปชัน: ui, validate, panel, lang, height, model, loadTimeout, baseUrl
add(name, bytes)โหลดไบต์ IFC (ArrayBuffer/Uint8Array) จากแอปของคุณ คืนค่า Promise พร้อมข้อมูลโมเดล
addFromUrl(url, name?)โหลด URL IFC สาธารณะที่เปิด CORS
select(expressId)เลือกและจัดเฟรมอิลิเมนต์ด้วย IFC expressID
isolate(ifcType?)แยกหมวดหมู่ (เช่น "IfcWall"); เว้นว่างเพื่อล้าง
setView(view)บินไปยังมุมกล้อง: iso, top, front, right, left, back, bottom
fit() · reset()จัดเฟรมโมเดลที่ใช้งาน / รีเซ็ตกล้อง
showAll()คืนการมองเห็นทั้งหมด (ล้างที่ซ่อน + การแยก)
setLanguage(lang)เปลี่ยนภาษาอินเทอร์เฟซขณะทำงาน
clear()ลบโมเดลที่โหลดไว้ทั้งหมด
getLanguages()แสดงรายการรหัสภาษาที่รองรับ (ป้ายกำกับดูที่ IfcViewer.LANGUAGES)
getModels()แสดงรายการโมเดลที่โหลด ({ id, fileName, elementCount }) คืนค่า Promise
getElement(id, modelId?)ดึงข้อมูล IFC ของอิลิเมนต์ (แอตทริบิวต์ + property/quantity set) คืนค่า Promise
getValidation()ดึงสรุปการตรวจสอบ (Health Score + จำนวน) คืนค่า Promise
getStats()จำนวนอิลิเมนต์ตามหมวดหมู่ของแต่ละโมเดล — สำหรับกราฟแดชบอร์ด คืนค่า Promise
getIssues(opts?)ปัญหาการตรวจสอบสำหรับตาราง (กรองตามระดับ / จำกัดจำนวน) คืนค่า Promise
checkIds(idsXml)Check the model against a buildingSMART IDS (.ids XML). Returns pass/fail per spec.
screenshot()จับภาพมุมมอง 3D ปัจจุบันเป็น PNG data URL คืนค่า Promise
removeModel(modelId)ยกเลิกการโหลดโมเดลตาม id
hideElements(ids) · showElements(ids)ซ่อน / แสดงชุดอิลิเมนต์ตาม expressID
setCamera(pos, dir)วางกล้องที่ตำแหน่งหนึ่งโดยมองไปตามทิศทาง
on(event, cb)สมัคร / ยกเลิกการรับอีเวนต์ คืนค่าฟังก์ชันสำหรับยกเลิก
dispose()รื้อและลบ iframe

อีเวนต์

เมธอดคำอธิบาย
readyตัวแสดงผลติดตั้งและพร้อม ({ languages })
model-progressความคืบหน้าการโหลด ({ percent, phase })
model-loadedโมเดลโหลดเสร็จแล้ว ({ modelId, fileName, elementCount })
validation-completedตรวจสอบเสร็จ — Health Score ({ qualityScore, errors, warnings, info })
model-errorการโหลดล้มเหลว ({ message })
element-selectedผู้ใช้เลือกอิลิเมนต์ ({ expressId, ifcType, name })
