IFC VIEWER SDK · v1.6.0

Incorpore o visualizador no seu próprio produto

Insira o mesmo visualizador do navegador no seu CDE, gémeo digital ou ferramentas internas de projeto. Carregue dados IFC da sua app enquanto o processamento do modelo permanece no cliente.

  • ✓ Sem backend de upload
  • ✓ Executa diretamente no navegador
  • ✓ Preparado para IFC, BCF e IDS

Início rápido

<div id="viewer" style="height:520px"></div>
<script type="module">
  import { IfcViewer } from "../ifc-viewer.es.js";

  const viewer = new IfcViewer("#viewer");

  const bytes = await fetch("/models/project.ifc").then(r => r.arrayBuffer());
  await viewer.add("project.ifc", bytes);
</script>

Ou, sem JS — use a etiqueta:

<script type="module" src="../ifc-viewer.es.js"></script>
<ifc-viewer model="https://host/project.ifc" ui="minimal"
            style="display:block;height:520px"></ifc-viewer>

O SDK descobre o URL da app relativamente a este script, por isso o auto-alojamento funciona logo.

API

MétodoDescrição
new IfcViewer(target, options?)Montar num seletor CSS ou elemento. Opções: ui, validate, panel, lang, height, model, loadTimeout, baseUrl.
add(name, bytes)Carregar bytes IFC (ArrayBuffer/Uint8Array) da sua app. Devolve uma promessa com a info do modelo.
addFromUrl(url, name?)Carregar um URL IFC público com CORS.
select(expressId)Selecionar e enquadrar um elemento pelo expressID IFC.
isolate(ifcType?)Isolar uma categoria (ex.: "IfcWall"); omitir para limpar.
setView(view)Voar para uma vista de câmara: iso, top, front, right, left, back, bottom.
fit() · reset()Enquadrar o modelo ativo / repor a câmara.
showAll()Restaurar toda a visibilidade (limpar ocultos + isolamento).
setLanguage(lang)Mudar o idioma da interface em tempo de execução.
clear()Remover todos os modelos carregados.
getLanguages()Listar os códigos de idioma suportados (rótulos em IfcViewer.LANGUAGES).
getModels()Lista os modelos carregados ({ id, fileName, elementCount }). Devolve uma promessa.
getElement(id, modelId?)Obtém os dados IFC de um elemento (atributos + property/quantity sets). Devolve uma promessa.
getValidation()Obtém o resumo de validação (Health Score + contagens). Devolve uma promessa.
getStats()Contagem de elementos por categoria e modelo — para gráficos. Devolve uma promessa.
getIssues(opts?)Problemas de validação para uma tabela (filtra por severidade / limite). Devolve uma promessa.
checkIds(idsXml)Check the model against a buildingSMART IDS (.ids XML). Returns pass/fail per spec.
screenshot()Captura a vista 3D atual como data URL PNG. Devolve uma promessa.
removeModel(modelId)Descarrega um modelo por id.
hideElements(ids) · showElements(ids)Oculta / mostra um conjunto de elementos por expressID.
setCamera(pos, dir)Coloca a câmara numa posição a olhar numa direção.
on(event, cb)Subscrever / cancelar eventos; devolve uma função para cancelar.
dispose()Desmontar e remover o iframe.

Eventos

MétodoDescrição
readyVisualizador montado e pronto ({ languages }).
model-progressProgresso do carregamento ({ percent, phase }).
model-loadedUm modelo terminou de carregar ({ modelId, fileName, elementCount }).
validation-completedValidação concluída — Health Score ({ qualityScore, errors, warnings, info }).
model-errorUm carregamento falhou ({ message }).
element-selectedO utilizador escolheu um elemento ({ expressId, ifcType, name }).

O modelo é obtido no navegador do visitante e analisado no cliente com WebAssembly — nada é enviado para os nossos servidores.
