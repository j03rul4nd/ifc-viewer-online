IFC VIEWER SDK · v1.6.0

将查看器嵌入您自己的产品

将同样的浏览器查看器嵌入您的 CDE、数字孪生或内部项目工具。直接从您的应用加载 IFC 数据，模型处理始终在客户端进行。

  • ✓ 无需上传后端
  • ✓ 直接在浏览器中运行
  • ✓ 支持 IFC、BCF 和 IDS

快速开始

<div id="viewer" style="height:520px"></div>
<script type="module">
  import { IfcViewer } from "../ifc-viewer.es.js";

  const viewer = new IfcViewer("#viewer");

  const bytes = await fetch("/models/project.ifc").then(r => r.arrayBuffer());
  await viewer.add("project.ifc", bytes);
</script>

或者，零 JS — 直接用标签：

<script type="module" src="../ifc-viewer.es.js"></script>
<ifc-viewer model="https://host/project.ifc" ui="minimal"
            style="display:block;height:520px"></ifc-viewer>

SDK 会相对于此脚本自动发现应用 URL，因此自托管开箱即用。

API

方法说明
new IfcViewer(target, options?)挂载到 CSS 选择器或元素。选项：ui、validate、panel、lang、height、model、loadTimeout、baseUrl。
add(name, bytes)从您的应用加载 IFC 字节（ArrayBuffer/Uint8Array）。返回包含模型信息的 Promise。
addFromUrl(url, name?)加载一个启用 CORS 的公开 IFC URL。
select(expressId)通过 IFC expressID 选择并聚焦一个元素。
isolate(ifcType?)隔离一个类别（如 "IfcWall"）；不传参则清除。
setView(view)切换相机视角：iso、top、front、right、left、back、bottom。
fit() · reset()适配当前模型 / 重置相机。
showAll()恢复全部可见性（清除隐藏与隔离）。
setLanguage(lang)在运行时切换界面语言。
clear()移除所有已加载的模型。
getLanguages()列出支持的语言代码（标签见 IfcViewer.LANGUAGES）。
getModels()列出已加载的模型（{ id, fileName, elementCount }）。返回 Promise。
getElement(id, modelId?)获取某元素的 IFC 数据（属性 + 属性集/数量集）。返回 Promise。
getValidation()获取当前校验摘要（健康分 + 计数）。返回 Promise。
getStats()按类别统计每个模型的元素数量——用于仪表盘图表。返回 Promise。
getIssues(opts?)用于表格的校验问题（按严重程度 / 数量过滤）。返回 Promise。
checkIds(idsXml)Check the model against a buildingSMART IDS (.ids XML). Returns pass/fail per spec.
screenshot()将当前三维视图捕获为 PNG data URL。返回 Promise。
removeModel(modelId)按 id 卸载某个模型。
hideElements(ids) · showElements(ids)按 expressID 隐藏 / 显示一组元素。
setCamera(pos, dir)将相机置于某位置并朝某方向观察。
on(event, cb)订阅 / 取消订阅事件；返回取消订阅的函数。
dispose()销毁并移除 iframe。

事件

方法说明
ready查看器已挂载并就绪（{ languages }）。
model-progress加载进度（{ percent, phase }）。
model-loaded某个模型加载完成（{ modelId, fileName, elementCount }）。
validation-completed校验完成——健康分（{ qualityScore, errors, warnings, info }）。
model-error一次加载失败（{ message }）。
element-selected用户选中了一个元素（{ expressId, ifcType, name }）。

模型在访问者的浏览器中获取，并使用 WebAssembly 在客户端解析——不会上传到我们的服务器。
