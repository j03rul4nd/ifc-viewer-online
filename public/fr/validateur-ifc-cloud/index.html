44 règles de validation

Ce que vérifie le validateur

Règles de schéma, hiérarchie, noms, complétude des données et géoréférencement — plus l’IDS 1.0 complète.

Intégrité des GUID

GlobalId en double et base64 invalide — l’erreur d’export la plus fréquente. Correction auto.

Hiérarchie spatiale

Chaîne Site → Building → Storey et éléments orphelins sans rattachement.

Noms et ISO 19650

Noms vides et libellés génériques qui cassent les métadonnées.

Jeux de propriétés

Psets requis absents ou vides pour le métré.

Géoréférencement

Décalages de plus de 10 km de l’origine — erreur classique de fédération.

Conformité IDS 1.0

Valide selon tout fichier .ids de buildingSMART sur les six facettes.

Questions

Questions


Est-ce un vrai validateur IFC cloud ?

Il offre tout ce qu’on attend d’un validateur IFC cloud — une URL dans n’importe quel navigateur, sans installation, des résultats instantanés, un rapport partageable — mais il traite le fichier sur votre propre appareil au lieu d’un serveur distant. L’IFC est analysé dans votre navigateur via WebAssembly, le modèle n’est donc jamais téléversé. La commodité du cloud sans le risque pour les données.

Pourquoi valider dans le navigateur plutôt que dans un cloud serveur ?

Les validateurs cloud côté serveur exigent de téléverser le modèle, ce que bloquent souvent les NDA, les accords clients ou les règles du secteur public. La validation dans le navigateur supprime ce blocage : pas de téléversement, pas de compte, rien à examiner avec l’équipe données du client — et c’est instantané, sans file d’attente.

Que vérifie-t-il ?

44 règles de qualité couvrant l’intégrité des GUID, la hiérarchie spatiale, les éléments orphelins, le nommage (ISO 19650), la complétude des Psets, les unités, la géométrie, l’excès de proxys et les décalages de coordonnées — plus un Health Score 0–100 et l’IDS 1.0 complète de buildingSMART.

Est-ce vraiment gratuit ?

Oui. Gratuit pour tous les usages, y compris commercial, sans compte ni mur payant lié à la taille. La visionneuse et le validateur sont open source sous licence MIT.

Puis-je partager les résultats ?

Oui. Après validation, « Partager le rapport » génère une URL encodant le Health Score et la liste des problèmes. Votre client l’ouvre dans n’importe quel navigateur — le fichier IFC n’est jamais inclus dans le lien.
