FAQ

Questions


What is a good free alternative to Solibri WebChecker?

IFC Viewer Online is a free, web-based IFC checker you open in any browser. It runs 44 quality rules and full buildingSMART IDS 1.0, returns a Health Score 0–100 in about 30 seconds, shows the 3D model, and exports BCF — without installing anything. Unlike server-based web checkers, the IFC is processed in your browser, so nothing is uploaded.

Does it run IFC checks in the browser like a web checker?

Yes — that is the core idea. Open a web page, drop an IFC, and the checks run client-side via WebAssembly. No desktop application, no upload step. Results stream in as each rule completes, and you can share a report URL with your client.

Can it replace Solibri entirely?

For web-based pre-delivery checking, IDS compliance and quality scoring — yes, for many teams. It does not aim to replace Solibri's enterprise custom rule authoring, COBie checking, full BCF lifecycle, or polygon-level clash detection on very large federated models. Many teams pre-screen in the browser and reserve Solibri for heavy enterprise coordination.

Is it free for commercial use?

Yes — free for all use cases including commercial work, no account, no file-size paywall. Open source under the MIT licence.
