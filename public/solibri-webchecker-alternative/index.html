Solibri WebChecker alternative that checks the IFC in your own browser

Solibri WebChecker (Beta) runs Solibri's checking engine online: you upload an IFC, it is checked on Solibri's service, and you download a PDF or BCF. It comes with the Advanced and Premium plans. If you need a web check without a plan, or without uploading the model, this page does it in your browser, with fewer checks.

Scope

What this check covers, and what it does not

It checks

  • Identifiers, spatial structure, storeys, names, property values, types and materials: 44 rules, 25 on by default.
  • IDS 1.0 files with their six facets.
  • Five built-in validation profiles, or your own naming patterns and required property sets.

It does not check

  • Solibri rulesets. A .cset file cannot be loaded here.
  • Hard clashes between disciplines, accessibility rules or space analysis.
  • Files of 2 GB or more.

Your file

What happens to the file

The IFC is read by code running in your browser tab and is not uploaded. The browser keeps a converted copy of the geometry in its private storage on your computer (up to 4 GB) to reopen it faster; clearing the site data removes it.

Usage statistics without cookies record the file size and the number of elements, never the content, and can be switched off. A share link, if you create one, carries the score, the file name and up to 50 issues inside the URL.

FAQ

Questions

What is Solibri WebChecker?

In Solibri's words, "a browser-based model validation service that runs Solibri's rules-based checking engine online". Users upload IFC models, run the Model Health check or a custom ruleset, and export PDF or BCF (solibri.com/solutions/webchecker, read on 2026-11-10).

Is Solibri WebChecker free?

No. It is included in Solibri Advanced and Premium and is not sold on its own. Each check uses 50 tokens from the plan's yearly allowance or from token packs that start at €250 for 5,000 tokens (solibri.com/solutions/webchecker, read on 2026-11-10).

Does WebChecker upload my model?

Yes: Solibri describes it as a service where users upload IFC models, with data stored in the EU or the US and results kept for 30 days (solibri.com/solutions/webchecker, read on 2026-11-10). IFC Viewer Online reads the file in your browser instead.

Can I run my Solibri rulesets here?

No. Solibri rulesets (.cset) only run in Solibri. Requirements that can be written as IDS 1.0 can be checked here.

Which one finds more problems?

They look for different things. WebChecker's Model Health check includes hard clashes between disciplines, which this page does not do. This page gives a score and automatic fixes for identifiers and names. For coordination, use Solibri.
