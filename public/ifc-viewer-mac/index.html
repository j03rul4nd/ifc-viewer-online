IFC Viewer for Mac that runs in the browser you already have

There is no app to download: the viewer is a web page. Open it in Safari or Chrome on macOS, drop an IFC file and you get the 3D model, the spatial tree, the properties of each element, sections, measurements and a validation report. The file is not uploaded.

On a Mac

What works on macOS, and what to expect

It works

  • In Safari, Chrome, Firefox and Edge on macOS. The page needs WebGL and WebAssembly, which those browsers include.
  • Opening .ifc files, and .ifczip or .zip archives, by dragging them into the window or with the Open button.
  • Several models at once, each with its own tree and properties.
  • On an iPad or iPhone too, with smaller files.

Keep in mind

  • It is not a macOS application: no Dock icon, no Quick Look preview, and .ifc files do not open with a double click.
  • The page has to load from the internet. It does not work offline.
  • The file-size limit is 2 GB, and in practice the memory of the Mac: a warning appears from 1 GB, or from 80 MB on machines with 4 GB of memory or less and on iPad and iPhone.
  • The captures on this page were made in Chrome. If something looks wrong in Safari, try Chrome.

Tools

What you can do with a model

Look

  • Orbit, pan and zoom; hide and isolate elements; browse the spatial tree.
  • Section planes and 2D floor plans cut from the model, exported as DXF, SVG or PDF.
  • Measure distances, areas, angles and clearances.
  • Read every property set and the quantities written in the file.

Check and fix

  • A validation with 44 rules and a Health Score from 0 to 100; see the IFC validator.
  • IDS 1.0 checks against your own requirements.
  • Edit names and property values, fix GlobalIds, and export the corrected IFC or a GLB.
  • Open and write BCF 2.1 and 3.0 files.

FAQ

Questions

Is there an IFC viewer for Mac that needs no installation?

Yes: this one is a web page. Open it in Safari, Chrome, Firefox or Edge on macOS and drop the file. There is nothing to download or install.

Does it work in Safari?

Yes. It needs WebGL and WebAssembly, which current versions of Safari include. The captures on this page were made in Chrome, so try Chrome if a model does not display well.

Is the IFC uploaded when I open it?

No. The file is read by code running in the browser tab. Only anonymous usage statistics (file size and element count) leave the browser, and they can be switched off.

Can I open Revit or Archicad files?

No, only IFC. Export an IFC from the authoring tool first.

Does it work offline on a Mac?

No. The page has to load from the internet each time, although the model itself is never sent.

Is Flinker available for Mac?

Flinker's viewer runs in the browser, so it can be used on a Mac that way; its desktop app is published for Windows and its site does not mention macOS (flinker.app/products/ifc-viewer, read on 2026-11-10).
