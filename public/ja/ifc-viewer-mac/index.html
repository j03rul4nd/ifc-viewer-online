ビューアを開く

macOS · Safari、Chrome、Firefox、Edge · インストール不要 · 無料

Mac 用 IFC ビューア お使いのブラウザでそのまま動きます

ダウンロードするアプリはありません。ビューアはウェブページです。macOS の Safari や Chrome で開いて IFC ファイルをドロップすると、3D モデル、空間ツリー、各要素のプロパティ、断面、計測、検証レポートが得られます。ファイルはアップロードされません。

ビューアを開く またはサンプルモデルを開く

アカウント不要。IFC2x3、IFC4、IFC4x1、IFC4x3、ファイルあたり 2 GB まで。

Mac では

macOS で動くものと、知っておくべきこと

動作するもの

  • macOS の Safari、Chrome、Firefox、Edge。このページには WebGL と WebAssembly が必要で、これらのブラウザに含まれています。
  • .ifc ファイル、および .ifczip や .zip のアーカイブを、ウィンドウにドラッグするか「開く」ボタンで開くこと。
  • 複数モデルの同時表示。それぞれに独自のツリーとプロパティがあります。
  • iPad や iPhone でも、より小さなファイルであれば。

留意点

  • macOS のアプリケーションではありません。Dock のアイコンも、クイックルックのプレビューもなく、.ifc ファイルをダブルクリックで開くこともできません。
  • ページをインターネットから読み込む必要があります。オフラインでは動作しません。
  • ファイルサイズの上限は 2 GB で、実際には Mac のメモリが上限になります。警告は 1 GB から、メモリ 4 GB 以下の機器と iPad、iPhone では 80 MB から表示されます。
  • このページのキャプチャは Chrome で撮影しました。Safari で表示がおかしい場合は、Chrome を試してください。

ツール

モデルでできること

見る

  • オービット、パン、ズーム。要素の非表示と分離。空間ツリーの閲覧。
  • 断面平面と、モデルから切り出した 2D の平面図。DXF、SVG、PDF としてエクスポートできます。
  • 距離、面積、角度、クリアランスの計測。
  • すべてのプロパティセットと、ファイルに書かれた数量の確認。

チェックして直す

  • 44 のルールと 0〜100 の Health Score による検証。IFC バリデーターをご覧ください。
  • 独自の要件に対する IDS 1.0 のチェック。
  • 名前とプロパティ値の編集、GlobalId の修正、修正済みの IFC または GLB のエクスポート。
  • BCF 2.1 と 3.0 のファイルを開く、書き出す。

FAQ

よくある質問

インストール不要の Mac 用 IFC ビューアはありますか？

はい。これはウェブページです。macOS の Safari、Chrome、Firefox、Edge で開き、ファイルをドロップしてください。ダウンロードするものもインストールするものもありません。

Safari で動きますか？

はい。WebGL と WebAssembly が必要で、現行バージョンの Safari に含まれています。このページのキャプチャは Chrome で撮影したので、モデルがうまく表示されない場合は Chrome を試してください。

IFC を開くとアップロードされますか？

いいえ。ファイルはブラウザのタブ内で動くコードが読み込みます。ブラウザの外に出るのは匿名の利用統計（ファイルサイズと要素数）だけで、無効にできます。

Revit や Archicad のファイルを開けますか？

いいえ、IFC のみです。先にオーサリングツールから IFC をエクスポートしてください。

Mac でオフラインで動きますか？

いいえ。ページは毎回インターネットから読み込む必要があります。ただし、モデル自体が送信されることはありません。

Flinker は Mac で使えますか？

Flinker のビューアはブラウザで動くので、その形で Mac でも使えます。デスクトップアプリは Windows 用として公開されており、サイトには macOS への言及がありません（flinker.app/products/ifc-viewer、閲覧日 2026-11-10）。
