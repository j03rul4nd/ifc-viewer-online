WordPress プラグイン

利用可能 無料

できること

投稿や固定ページにインタラクティブな 3D IFC モデルを表示するブロックと [ifc_viewer] ショートコード。

対象

WordPress サイトでプロジェクトや製品を公開する建築家、エンジニア、メーカー。

インストール
  1. WordPress で プラグイン → 新規追加 を開く。
  2. 「Bimo IFC Viewer」を検索してインストールし、有効化する。
  3. IFC Viewer ブロックを追加するか、公開 IFC の URL で [ifc_viewer model="…"] を貼り付ける。
制限

IFC は URL でアクセスできる必要があります（メディアライブラリや公開リンク）。非常に大きなモデルはスマートフォンでは読み込みが遅くなります。

wordpress.org で入手

Shopify アプリ

審査中

できること

商品やバリエーションごとの IFC モデル、モデルから読み取った仕様表、商品ページでのファイルダウンロード。

対象

Shopify で製品を販売・掲載する建材メーカー。

インストール
  1. 承認後、Shopify App Store からアプリをインストールする。
  2. 商品またはバリエーションに IFC ファイルを紐づける。
  3. テーマエディタで商品テンプレートにビューアブロックを追加する。
制限

アプリは Shopify App Store に申請済みで審査中のため、まだインストールできません。プラン：Free、Starter、Business。現在は GitHub から無料のテーマセクションをコピーできます。

JavaScript SDK

利用可能 無料

できること

自社の Web アプリにビューアを組み込み、コードから IFC バイトを読み込む。選択・色・カメラのイベントと API 付き。

対象

CDE、ポータル、社内ツールの開発者。

インストール
  1. /sdk/ifc-viewer.es.js から SDK モジュールをインポートする。
  2. ページの要素にビューアを作成する。
  3. viewer.add() でアプリから IFC バイトを渡す。
制限

ブラウザでのみ動作し、ホストするページが必要です。SDK はファイルを保存しません。

埋め込み（iframe）

利用可能 無料

できること

iframe を 1 つ貼るだけで任意のページにモデルを表示。カメラ、色、パネルは埋め込みビルダーで設定。

対象

コードを書かずに Web サイト、ブログ、CMS で見せたい人。

インストール
  1. 埋め込みビルダーを開く。
  2. 公開 IFC の URL を貼り、ビューを設定する。
  3. iframe をページにコピーする。
制限

モデルの URL はクロスオリジン要求（CORS）を許可している必要があります。iframe には約 400 px の高さが必要です。

デスクトップツール用ローカルサーバー（MCP）

利用可能 無料

できること

Model Context Protocol に対応したデスクトップアプリやコードエディタから、IFC の検証、IDS チェック、3D 表示ができるローカルサーバー。

対象

デスクトップツールで IFC を扱う BIM コーディネーターと開発者。

インストール
  1. Node.js 18 以降をインストールする。
  2. ツールの MCP 設定にサーバー「npx -y ifc-viewer-mcp」を追加する。
  3. ツールを再起動し、ディスク上の IFC ファイルを指定する。
制限

MCP 対応のデスクトップツールと Node.js が必要です。検証は手元の PC で実行され、3D 表示はブラウザで開きます。
