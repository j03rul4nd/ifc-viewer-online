การผสานรวม

ตัวแสดงผลบนเบราว์เซอร์ตัวเดิม ในเครื่องมือที่คุณใช้อยู่แล้ว โมเดลประมวลผลบนอุปกรณ์ของผู้ชม ไม่มีการอัปโหลดมาที่เรา

ปลั๊กอิน WordPressแอป ShopifyJavaScript SDKฝัง (iframe)เซิร์ฟเวอร์ภายในเครื่องสำหรับเครื่องมือเดสก์ท็อป (MCP)

ปลั๊กอิน WordPress

พร้อมใช้ ฟรี

ทำอะไรได้

บล็อกและชอร์ตโค้ด [ifc_viewer] ที่แสดงโมเดล IFC 3D แบบโต้ตอบได้ในโพสต์และหน้า

เหมาะกับใคร

สถาปนิก วิศวกร และผู้ผลิตที่เผยแพร่โครงการหรือสินค้าบนเว็บไซต์ WordPress

การติดตั้ง
  1. ใน WordPress เปิด ปลั๊กอิน → เพิ่มใหม่
  2. ค้นหา “Bimo IFC Viewer” ติดตั้งและเปิดใช้งาน
  3. เพิ่มบล็อก IFC Viewer หรือวาง [ifc_viewer model="…"] พร้อม URL สาธารณะของ IFC
ข้อจำกัด

ไฟล์ IFC ต้องเข้าถึงได้ผ่าน URL (คลังสื่อหรือลิงก์สาธารณะ) โมเดลขนาดใหญ่มากจะโหลดช้าบนมือถือ

รับที่ wordpress.org

แอป Shopify

กำลังตรวจสอบ

ทำอะไรได้

โมเดล IFC ต่อสินค้าหรือตัวเลือก ตารางสเปกที่อ่านจากโมเดล และการดาวน์โหลดไฟล์บนหน้าสินค้า

เหมาะกับใคร

ผู้ผลิตวัสดุก่อสร้างที่ขายหรือแสดงสินค้าบน Shopify

การติดตั้ง
  1. ติดตั้งแอปจาก Shopify App Store เมื่อได้รับอนุมัติ
  2. ผูกไฟล์ IFC กับสินค้าหรือตัวเลือก
  3. เพิ่มบล็อกตัวแสดงผลในเทมเพลตสินค้าผ่านตัวแก้ไขธีม
ข้อจำกัด

แอปส่งเข้า Shopify App Store แล้วและอยู่ระหว่างตรวจสอบ จึงยังติดตั้งไม่ได้ แพ็กเกจ: Free, Starter และ Business ตอนนี้คุณคัดลอกส่วนของธีมฟรีจาก GitHub ได้

รับส่วนของธีมฟรี

JavaScript SDK

พร้อมใช้ ฟรี

ทำอะไรได้

ฝังตัวแสดงผลในเว็บแอปของคุณและโหลดไบต์ IFC จากโค้ด พร้อมอีเวนต์และ API สำหรับการเลือก สี และกล้อง

เหมาะกับใคร

นักพัฒนา CDE พอร์ทัล และเครื่องมือภายใน

การติดตั้ง
  1. นำเข้าโมดูล SDK จาก /sdk/ifc-viewer.es.js
  2. สร้างตัวแสดงผลบนองค์ประกอบในหน้าของคุณ
  3. ส่งไบต์ IFC จากแอปด้วย viewer.add()
ข้อจำกัด

ทำงานในเบราว์เซอร์เท่านั้น ต้องมีหน้าเว็บสำหรับโฮสต์ SDK ไม่เก็บไฟล์ให้คุณ

อ่านเอกสาร

ฝัง (iframe)

พร้อมใช้ ฟรี

ทำอะไรได้

วาง iframe เดียวเพื่อแสดงโมเดลในหน้าใดก็ได้ ตั้งค่ากล้อง สี และแผงได้ในตัวสร้างโค้ดฝัง

เหมาะกับใคร

ทุกคนที่มีเว็บไซต์ บล็อก หรือ CMS และไม่อยากเขียนโค้ด

การติดตั้ง
  1. เปิดตัวสร้างโค้ดฝัง
  2. วาง URL สาธารณะของ IFC และตั้งค่ามุมมอง
  3. คัดลอก iframe ไปใส่ในหน้าของคุณ
ข้อจำกัด

URL ของโมเดลต้องอนุญาตคำขอข้ามโดเมน (CORS) iframe ต้องสูงประมาณ 400 px จึงใช้งานสะดวก

เปิดตัวสร้างโค้ดฝัง

เซิร์ฟเวอร์ภายในเครื่องสำหรับเครื่องมือเดสก์ท็อป (MCP)

พร้อมใช้ ฟรี

ทำอะไรได้

เซิร์ฟเวอร์ภายในเครื่องที่ให้แอปเดสก์ท็อปและโปรแกรมแก้ไขโค้ดที่รองรับ Model Context Protocol ตรวจสอบ IFC ตรวจ IDS และเปิดโมเดลเป็น 3D

เหมาะกับใคร

ผู้ประสานงาน BIM และนักพัฒนาที่ทำงานกับ IFC จากเครื่องมือเดสก์ท็อป

การติดตั้ง
  1. ติดตั้ง Node.js 18 ขึ้นไป
  2. เพิ่ม “npx -y ifc-viewer-mcp” เป็นเซิร์ฟเวอร์ในการตั้งค่า MCP ของเครื่องมือ
  3. รีสตาร์ตเครื่องมือแล้วชี้ไปที่ไฟล์ IFC ในดิสก์ของคุณ
ข้อจำกัด

ต้องมีเครื่องมือเดสก์ท็อปที่รองรับ MCP และ Node.js การตรวจสอบทำบนเครื่องของคุณ มุมมอง 3D เปิดในเบราว์เซอร์
