IFC Viewer สำหรับ Mac ที่ทำงานในเบราว์เซอร์ที่คุณมีอยู่แล้ว

ไม่มีแอปให้ดาวน์โหลด: วิวเวอร์เป็นหน้าเว็บ เปิดใน Safari หรือ Chrome บน macOS ลากไฟล์ IFC มาวาง แล้วจะได้โมเดล 3D โครงสร้างต้นไม้เชิงพื้นที่ property ของแต่ละองค์ประกอบ section การวัด และรายงานการตรวจสอบ ไฟล์ไม่ถูกอัปโหลด

เปิดวิวเวอร์ หรือเปิดโมเดลตัวอย่าง

ไม่ต้องมีบัญชี รองรับ IFC2x3, IFC4, IFC4x1 และ IFC4x3 สูงสุด 2 GB ต่อไฟล์

บน Mac

อะไรใช้ได้บน macOS และควรคาดหวังอะไร

ใช้ได้

  • ใน Safari, Chrome, Firefox และ Edge บน macOS หน้าเว็บต้องใช้ WebGL และ WebAssembly ซึ่งเบราว์เซอร์เหล่านี้มีอยู่แล้ว
  • เปิดไฟล์ .ifc และไฟล์บีบอัด .ifczip หรือ .zip โดยลากมาวางในหน้าต่างหรือใช้ปุ่ม Open
  • หลายโมเดลพร้อมกัน แต่ละโมเดลมีต้นไม้และ property ของตัวเอง
  • บน iPad หรือ iPhone ก็ได้ กับไฟล์ที่เล็กกว่า

ข้อควรทราบ

  • ไม่ใช่แอปพลิเคชัน macOS: ไม่มีไอคอนใน Dock ไม่มีพรีวิว Quick Look และดับเบิลคลิกไฟล์ .ifc แล้วไม่เปิด
  • หน้าเว็บต้องโหลดจากอินเทอร์เน็ต ใช้งานแบบออฟไลน์ไม่ได้
  • ขีดจำกัดขนาดไฟล์คือ 2 GB และในทางปฏิบัติคือหน่วยความจำของ Mac: มีคำเตือนตั้งแต่ 1 GB หรือตั้งแต่ 80 MB บนเครื่องที่มีหน่วยความจำ 4 GB หรือน้อยกว่า และบน iPad กับ iPhone
  • ภาพในหน้านี้จับใน Chrome หากมีอะไรแสดงผิดปกติใน Safari ให้ลอง Chrome

เครื่องมือ

ทำอะไรกับโมเดลได้บ้าง

ดู

  • หมุน เลื่อน และซูม ซ่อนและแยกแสดงองค์ประกอบ ไล่ดูต้นไม้เชิงพื้นที่
  • ระนาบ section และแปลนพื้น 2D ที่ตัดจากโมเดล export เป็น DXF, SVG หรือ PDF
  • วัดระยะ พื้นที่ มุม และระยะห่าง (clearance)
  • อ่าน property set ทุกชุดและปริมาณที่เขียนไว้ในไฟล์

ตรวจและแก้

  • การตรวจสอบด้วย 44 กฎและ Health Score ตั้งแต่ 0 ถึง 100 ดูตัวตรวจสอบ IFC
  • การตรวจ IDS 1.0 กับข้อกำหนดของคุณเอง
  • แก้ชื่อและค่า property แก้ GlobalId และ export IFC ที่แก้ไขแล้วหรือ GLB
  • เปิดและเขียนไฟล์ BCF 2.1 และ 3.0

FAQ

คำถามที่พบบ่อย

มี IFC viewer สำหรับ Mac ที่ไม่ต้องติดตั้งหรือไม่

มี: ตัวนี้เป็นหน้าเว็บ เปิดใน Safari, Chrome, Firefox หรือ Edge บน macOS แล้วลากไฟล์มาวาง ไม่มีอะไรต้องดาวน์โหลดหรือติดตั้ง

ใช้ใน Safari ได้หรือไม่

ได้ ต้องใช้ WebGL และ WebAssembly ซึ่ง Safari รุ่นปัจจุบันมีอยู่แล้ว ภาพในหน้านี้จับใน Chrome ดังนั้นหากโมเดลแสดงผลไม่ดีให้ลอง Chrome

IFC ถูกอัปโหลดเมื่อเปิดหรือไม่

ไม่ ไฟล์ถูกอ่านโดยโค้ดที่ทำงานในแท็บเบราว์เซอร์ สิ่งที่ออกจากเบราว์เซอร์มีเพียงสถิติการใช้งานแบบไม่ระบุตัวตน (ขนาดไฟล์และจำนวนองค์ประกอบ) และปิดได้

เปิดไฟล์ Revit หรือ Archicad ได้หรือไม่

ไม่ได้ เฉพาะ IFC ให้ export IFC จากโปรแกรมที่ใช้สร้างโมเดลก่อน

ใช้ออฟไลน์บน Mac ได้หรือไม่

ไม่ได้ หน้าเว็บต้องโหลดจากอินเทอร์เน็ตทุกครั้ง แม้ตัวโมเดลเองจะไม่ถูกส่งออกไปเลย

Flinker มีสำหรับ Mac หรือไม่

วิวเวอร์ของ Flinker ทำงานในเบราว์เซอร์ จึงใช้บน Mac ได้ด้วยวิธีนั้น ส่วนแอปเดสก์ท็อปเผยแพร่สำหรับ Windows และเว็บไซต์ไม่ได้กล่าวถึง macOS (flinker.app/products/ifc-viewer, อ่านเมื่อ 2026-11-10)
