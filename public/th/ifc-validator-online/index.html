เปิดตัวดู

44 กฎ · IDS 1.0 · ไฟล์อยู่ในเบราว์เซอร์ของคุณ · ฟรี

ตรวจสอบ IFC ออนไลน์ ไฟล์ผิดตรงไหน และผิดที่องค์ประกอบใด

ลากไฟล์ IFC มาวาง แล้วจะได้ Health Score ตั้งแต่ 0 ถึง 100 รายการปัญหาที่จัดกลุ่มตามกฎ และองค์ประกอบที่ไม่ผ่านซึ่งถูกไฮไลต์ในโมเดล 3D ไฟล์ถูกอ่านในแท็บเบราว์เซอร์ของคุณและไม่ถูกอัปโหลด

ตรวจสอบไฟล์ IFC หรือเปิดโมเดลตัวอย่าง

ไม่ต้องมีบัญชี รองรับ IFC2x3, IFC4, IFC4x1 และ IFC4x3 สูงสุด 2 GB ต่อไฟล์

ขอบเขต

การตรวจครอบคลุมอะไร และไม่ครอบคลุมอะไร

มี 44 กฎในแปดกลุ่ม 25 กฎทำงานเป็นค่าเริ่มต้น อีก 19 กฎเปิดใช้จากโปรไฟล์ เพราะต้องให้คุณตัดสินใจก่อน (ระดับ LOD รูปแบบการตั้งชื่อ ระบบ classification)

สิ่งที่ตรวจ

  • ตัวระบุ: GlobalId ซ้ำ และ GlobalId ที่ไม่ใช่ IFC GUID 22 อักขระที่ถูกต้อง
  • โครงสร้าง: IfcProject หนึ่งรายการ ลำดับ Project → Site → Building → Storey องค์ประกอบที่ไม่อยู่ในชั้นใด aggregation ที่ขาดหรือวนเป็นวงกลม ช่องเปิดที่ไม่มีองค์ประกอบหลัก (host)
  • ชั้น: ระดับความสูงที่ขาดหาย ซ้ำกัน หรือไม่เรียงลำดับ
  • ข้อมูล: ชื่อว่าง ชื่อซ้ำ ค่า property ว่าง องค์ประกอบที่ไม่มี type หรือวัสดุ space ที่ไม่มีพื้นที่พื้น
  • คุณภาพการ export: องค์ประกอบมากกว่า 5% เป็น IfcBuildingElementProxy โมเดลอยู่ห่างจากจุดกำเนิดมากกว่า 10 km มากกว่า 500 KB ต่อองค์ประกอบ หน่วยความยาวแบบอิมพีเรียล
  • เมื่อเปิดใช้: property set ที่กำหนดต่อคลาส รูปแบบการตั้งชื่อ classification property และปริมาณตาม LOD 100–400 ฟิลด์โครงการและผู้จัดทำตาม ISO 19650 ระบบ MEP
  • ข้อกำหนดของคุณเอง: ไฟล์ IDS 1.0 หนึ่งในห้าโปรไฟล์ในตัว (การส่งมอบพื้นฐาน การทบทวนคุณภาพ การประสานงาน BIM, ISO 19650, LOD 300) หรือโปรไฟล์ที่คุณกำหนดเอง

สิ่งที่ไม่ตรวจ

  • Clash ระหว่างสองโมเดล กฎ clash เทียบ bounding box ภายในโมเดลเดียว โดยมีระยะซ้อนทับ 5 cm สูงสุด 800 องค์ประกอบและ 100 ผลลัพธ์ เป็นเพียงการกรองขั้นแรก ไม่ใช่การประสานงาน
  • กฎหมายอาคาร: การเข้าถึงสำหรับคนพิการ ความปลอดภัยจากอัคคีภัย เส้นทางหนีไฟ หรือความสูงสุทธิ ไม่มีกฎใดที่นี่อ่านข้อบังคับ
  • สคีมา IFC ทั้งหมด นี่ไม่ใช่การทดสอบ conformance ของ EXPRESS: รันเฉพาะ 44 กฎนี้และ IDS ของคุณ
  • รหัสตาม ISO 19650 กฎชื่อไฟล์อ่านชื่อที่เขียนไว้ใน header ของ IFC แล้วนับจำนวนฟิลด์ ไม่ได้ตรวจรหัสทีละตัว
  • ไฟล์ native อ่านได้เฉพาะ IFC ไม่อ่านไฟล์ Revit หรือ Archicad

ข้อจำกัด พร้อมตัวเลข

ข้อจำกัด
ขนาดไฟล์ไฟล์ขนาด 2 GB จะถูกปฏิเสธ มีข้อความแจ้งตั้งแต่ 200 MB และคำเตือนเรื่องหน่วยความจำตั้งแต่ 1 GB บนโทรศัพท์ แท็บเล็ต และคอมพิวเตอร์ที่มีหน่วยความจำ 4 GB หรือน้อยกว่า คำเตือนเริ่มที่ 80 MB
รูปแบบIFC2x3, IFC4, IFC4x1 และ IFC4x3 เป็นไฟล์ .ifc หรืออยู่ใน .ifczip และ .zip
กฎทั้งหมด 44 กฎ เปิดเป็นค่าเริ่มต้น 25 กฎ ปรับระดับความรุนแรงและค่าเกณฑ์ได้ทีละกฎ
IDSIDS 1.0 พร้อม facet ทั้งหก ไม่อ่าน restriction แบบ totalDigits, fractionDigits และ whiteSpace แสดงองค์ประกอบที่ไม่ผ่านได้สูงสุด 200 รายการต่อ specification
การแก้ไขอัตโนมัติGlobalId ที่ไม่ถูกต้องและซ้ำ และชื่อที่ว่างหรือซ้ำ ที่เหลือคุณต้องแก้ด้วยมือหรือแก้ในโปรแกรมที่ใช้สร้างโมเดล
ความเร็วตัวอย่างในภาพ (2.3 MB, 7,181 เอนทิตี) ใช้เวลาตรวจสอบประมาณ 20 วินาทีบนคอมพิวเตอร์ที่ใช้จับภาพเหล่านี้ เวลาเพิ่มขึ้นตามจำนวนเอนทิตี
การเชื่อมต่อหน้าเว็บต้องโหลดจากอินเทอร์เน็ต ใช้งานแบบออฟไลน์ไม่ได้

ไฟล์ของคุณ

เกิดอะไรขึ้นกับไฟล์

IFC ถูกเปิดโดยโค้ดที่ทำงานในแท็บเบราว์เซอร์ของคุณ ไม่ถูกส่งมาที่เราหรือใครอื่น จึงไม่ต้องรออัปโหลดและไม่มีอะไรต้องลบภายหลัง

เพื่อให้เปิดโมเดลซ้ำได้เร็วขึ้น เบราว์เซอร์จะเก็บสำเนาเรขาคณิตที่แปลงแล้วไว้ในพื้นที่จัดเก็บส่วนตัวของเบราว์เซอร์บนคอมพิวเตอร์ของคุณ (สูงสุด 4 GB ของเก่าสุดถูกลบออกก่อน) การล้างข้อมูลไซต์ในเบราว์เซอร์จะลบสำเนานี้

มีสองอย่างที่ออกจากเบราว์เซอร์ และคุณควบคุมได้ทั้งคู่ สถิติการใช้งานแบบไม่ใช้คุกกี้บันทึกว่ามีการเปิดไฟล์ ขนาดไฟล์ และจำนวนองค์ประกอบ ไม่บันทึกเนื้อหา ปิดได้และเคารพ Do Not Track และถ้าคุณกด Share ตัวลิงก์เองจะบรรจุคะแนน ชื่อไฟล์ และปัญหา 50 รายการแรกพร้อมชื่อองค์ประกอบ ดังนั้นใครก็ตามที่มีลิงก์จะอ่านข้อมูลเหล่านั้นได้

ผลลัพธ์

จากคะแนนไปถึงองค์ประกอบ

ลองที่นี่กับโมเดลตัวอย่าง แล้วค่อยเปิดไฟล์ของคุณเอง

ขั้นตอน

จากไฟล์สู่ IFC ที่แก้ไขแล้ว

  1. เปิดไฟล์

    ลากไฟล์ .ifc มาวางในหน้า เปิดหลายไฟล์พร้อมกันได้ แต่ละไฟล์ถูกตรวจสอบแยกกัน

  2. อ่านผล

    คะแนน ข้อผิดพลาดและคำเตือน และการแก้ไขสามข้อที่ได้คะแนนคืนมากที่สุด คลิกครั้งเดียวเพื่อไฮไลต์องค์ประกอบที่ไม่ผ่าน

  3. แก้สิ่งที่แก้ได้ที่นี่

    สร้าง GlobalId ที่ไม่ถูกต้องใหม่ เปลี่ยนชื่อเป็นชุด แก้ชื่อและค่า property ทุกการแก้ไขยกเลิกได้

  4. Export

    IFC ที่แก้ไขแล้วซึ่ง parser เขียนขึ้นใหม่ และผลการตรวจเป็น BCF 2.1, CSV, JSON รายงานส่งมอบแบบ HTML หรือสเปรดชีต COBie

FAQ

คำถามที่พบบ่อย

ไฟล์ IFC ถูกอัปโหลดไปยังเซิร์ฟเวอร์หรือไม่

ไม่ ไฟล์ถูกอ่านโดยโค้ดที่ทำงานในแท็บเบราว์เซอร์ของคุณ สิ่งที่ออกจากเบราว์เซอร์มีเพียงสถิติการใช้งานแบบไม่ระบุตัวตน (ขนาดไฟล์และจำนวนองค์ประกอบ ไม่มีเนื้อหา) และลิงก์แชร์ที่คุณสร้างเอง

อ่าน IFC เวอร์ชันใดได้บ้าง

IFC2x3, IFC4, IFC4x1 และ IFC4x3 เป็นไฟล์ .ifc หรืออยู่ในไฟล์บีบอัด .ifczip และ .zip ไฟล์ขนาด 2 GB ขึ้นไปจะถูกปฏิเสธ

ใช้แทนเครื่องมือ clash detection ได้หรือไม่

ไม่ได้ กฎ clash เทียบ bounding box ภายในโมเดลเดียวและปิดอยู่เป็นค่าเริ่มต้น ใช้หาการซ้อนทับที่เห็นชัดก่อนส่งโมเดลต่อ การประสานงานระหว่างสาขางานต้องใช้เครื่องมือ clash

ตรวจโมเดลกับข้อกำหนดของตัวเองได้หรือไม่

ได้ โหลดไฟล์ IDS 1.0 หรือเริ่มจากชุดข้อกำหนดสำเร็จรูปหนึ่งในเจ็ดชุด (การส่งมอบตาม ISO 19650, LOD 200 และ LOD 400, การส่งมอบ COBie และอื่นๆ) คุณยังสร้างโปรไฟล์การตรวจสอบที่มีรูปแบบการตั้งชื่อและ property set ที่กำหนดของคุณเองได้ด้วย

แก้ข้อผิดพลาดแล้ว export IFC ใหม่ได้หรือไม่

GlobalId และชื่อแก้อัตโนมัติได้ ชื่อ คำอธิบาย และค่า property แก้ด้วยมือได้และยกเลิกได้ การ export จะเขียน IFC ใหม่พร้อมการเปลี่ยนแปลงเหล่านั้น เรขาคณิตและ relationship แก้ไขไม่ได้

ใช้งานโดยไม่มีอินเทอร์เน็ตได้หรือไม่

ไม่ได้ หน้าเว็บต้องโหลดจากอินเทอร์เน็ต สำหรับเครือข่ายที่ไม่มีอินเทอร์เน็ตมีการติดตั้งแบบ on-premise
