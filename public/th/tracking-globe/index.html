ประมาณ 30 KB โหลดสองขั้น
ตัวโหลด 3 KB จองพื้นที่ไว้ หน้าจึงไม่กระโดด เอนจิน 27 KB มาเมื่อแผนที่ใกล้ถึงหน้าจอ ไม่มีไลบรารีแผนที่หรือเซิร์ฟเวอร์ไทล์
ไม่ต้องขอความยินยอม
ไม่มีคุกกี้ การวิเคราะห์ หรือการเรียกบุคคลที่สาม แผนที่โลกอยู่ในไฟล์ IP ของผู้เข้าชมจึงไม่ถูกส่งให้ผู้ให้บริการแผนที่
ปรับได้ตามต้องการ
ตั้งสี ฟอนต์ โลโก้ และภาษาในแบบฟอร์ม CSS ของคุณตั้ง --tg-accent และค่าอื่น ๆ และเข้าถึงส่วนต่าง ๆ ด้วย ::part() ได้


คำถาม
นี่คือเครื่องติดตาม GPS แบบเรียลไทม์หรือไม่?
ไม่ใช่ มันวาดข้อมูลที่คุณให้: วันที่ ความคืบหน้า หรือตำแหน่งจากระบบของคุณ ไม่ได้เชื่อมต่อกับสายการเดินเรือหรือเรือ เส้นทางเป็นแบบแผนผัง ไม่ใช่เพื่อการนำทาง
แสดงการขนส่งจำลองได้ไหม?
ได้ สำหรับเดโมและหน้าขาย โดยจะมีป้าย “ข้อมูลจำลอง” เสมอ เพื่อไม่ให้เข้าใจผิดว่าเป็นสินค้าจริง
จะเก็บข้อมูลการขนส่งเป็นส่วนตัวอย่างไร?
อย่าวางไว้ในโค้ด ให้ชี้วิดเจ็ตไปยังเซิร์ฟเวอร์ของคุณและใช้การค้นหา ซึ่งดึงทีละเลขอ้างอิงตามกฎของคุณ
ใช้ใน SharePoint ได้ไหม?
ได้ผ่าน Embed web part แบบ iframe เมื่อเจ้าของไซต์อนุญาตโดเมน สคริปต์ในเนื้อหาจะไม่ทำงานที่นั่น เรายังไม่ได้ทดสอบใน tenant จริง
ใช้บน Taobao ได้ไหม?
ไม่ได้ในรูปแบบวิดเจ็ตสด เท่าที่ยืนยันได้ คุณเผยแพร่รูปแผนที่และโฮสต์เวอร์ชันสดในหน้าของคุณเองได้
มีค่าใช้จ่ายไหม?
ไม่ต้องมีบัญชีและไม่มีค่าธรรมเนียม ทำงานในเบราว์เซอร์ของผู้เข้าชม จึงไม่มีเซิร์ฟเวอร์ของเราที่ต้องจ่าย
แผนที่ 3D ทำงานในอีเมลได้ไหม?
ไม่ได้ โปรแกรมอีเมลไม่รันสคริปต์ อีเมลมีรูปหรือ GIF และลิงก์ส่วนตัว ส่วนแผนที่โต้ตอบเปิดในหน้าติดตาม
วัดยอดขายอย่างไร?
แพลตฟอร์มอีเมลนับการคลิกลิงก์ ทุกลิงก์ขาออกมีแท็กแคมเปญ การวิเคราะห์ร้านค้าจึงระบุที่มาของยอดขายได้ เปรียบเทียบกับกลุ่มที่ได้รับอีเมลปกติเพื่อวัดผลจริง
