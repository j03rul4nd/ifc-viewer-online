ขอบเขต

สิ่งที่ได้ที่นี่ และสิ่งที่ไม่ได้

สิ่งที่ได้

  • Health Score ตั้งแต่ 0 ถึง 100 และการแก้ไขที่ได้คะแนนคืนมากที่สุด
  • องค์ประกอบที่ไม่ผ่านถูกไฮไลต์ในโมเดล 3D และแสดงรายการตามกฎ ชั้น หรือคลาส
  • การตรวจ IDS 1.0 และโปรไฟล์การตรวจสอบในตัวห้าแบบ ตั้งแต่การส่งมอบพื้นฐานจนถึง ISO 19650 และ LOD 300
  • การแก้ไขอัตโนมัติสำหรับ GlobalId และชื่อ การแก้ชื่อและค่า property ด้วยมือ และ IFC ที่แก้ไขแล้ว
  • ผลการตรวจเป็น BCF 2.1, CSV, JSON รายงาน HTML หรือสเปรดชีต COBie

สิ่งที่ไม่ได้

  • Clash detection ระหว่างโมเดล หรือในระดับเรขาคณิตจริง
  • ตัวแก้ไขกฎ การตรวจตามกฎหมายอาคาร (การเข้าถึง อัคคีภัย เส้นทางหนีไฟ) หรือการวิเคราะห์ space
  • การติดตาม issue พร้อมการมอบหมายงานบนเซิร์ฟเวอร์ ไฟล์ BCF ต้องแลกเปลี่ยนกันเอง
  • ไฟล์ขนาด 2 GB ขึ้นไป ขีดจำกัดขึ้นกับหน่วยความจำของคอมพิวเตอร์คุณ

FAQ

คำถามที่พบบ่อย

IFC Viewer Online ใช้แทน Solibri ได้หรือไม่

สำหรับการตรวจ IFC ไฟล์เดียวก่อนส่งมอบ (ตัวระบุ โครงสร้างเชิงพื้นที่ ชื่อ property และ IDS) ได้ สำหรับ clash detection ระหว่างสาขางาน กฎแบบกำหนดเอง และการกำกับดูแลข้ามโครงการ ไม่ได้: นั่นคืองานของ Solibri Essential และ Advanced

Solibri ราคาเท่าใด

Solibri เผยแพร่ราคาเริ่มต้นต่อ licence ต่อปี: Starter €99, Essential €1,428, Advanced €2,109 และ Premium €2,772 ส่วน Security+ ต้องสอบถามราคา (solibri.com/pricing, อ่านเมื่อ 2026-11-10)

Solibri มีเวอร์ชันฟรีหรือไม่

Solibri Anywhere ซึ่งเคยมีเวอร์ชันฟรี ตอนนี้เป็นผลิตภัณฑ์ legacy และไม่เปิดให้ลูกค้าใหม่ ผู้ใช้ฟรีเดิมยังใช้เวอร์ชันก่อน 26.4.0 ต่อได้ (solibri.com/products/legacy-products, อ่านเมื่อ 2026-11-10) แผนปัจจุบันที่ถูกที่สุดคือ Starter ราคา €99 ต่อปี

แผน Starter ราคา €99 ตรวจโมเดลได้หรือไม่

ตามที่ Solibri ระบุ Starter ใช้สำหรับการตรวจดูด้วยสายตาและทบทวนผลลัพธ์ที่ผู้อื่นทำไว้: "Model checking is performed in Solibri Essential, Advanced, or Premium" (solibri.com/products/starter, อ่านเมื่อ 2026-11-10)

Solibri ทำอะไรได้ที่เครื่องมือนี้ทำไม่ได้

Clash detection บนเรขาคณิตจริงและระหว่างโมเดล กฎที่เขียนขึ้นสำหรับองค์กรของคุณ กฎการถอดปริมาณ โมเดล Revit แบบ native, BCF server และการเชื่อมต่อ CDE และแผนที่ทำงานออฟไลน์เต็มรูปแบบ ดูตารางด้านบน

ใช้ทั้งสองอย่างได้หรือไม่

ได้ และเป็นการแบ่งงานที่พบบ่อย: ผู้จัดทำโมเดลและเจ้าของงานตรวจไฟล์ในเบราว์เซอร์ก่อนส่ง และทีมประสานงานรัน Solibri กับโมเดลรวม (federated model)
