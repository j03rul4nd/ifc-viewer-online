On-premise · ไม่ต่ออินเทอร์เน็ต · เซิร์ฟเวอร์ของคุณ

ตัวตรวจสอบ IFC แบบ On-Premise สำหรับเครือข่ายที่ต้องปิดไว้

แอปสาธารณะอ่านไฟล์ IFC ภายในเบราว์เซอร์อยู่แล้ว แต่ตัวหน้าเว็บเองโหลดจากอินเทอร์เน็ต ในที่ที่ไม่อนุญาตเช่นนั้น วิวเวอร์ ตัวตรวจสอบ และการตรวจ IDS ชุดเดียวกันจะให้บริการจาก container บนเซิร์ฟเวอร์ของคุณเอง

ขอทำโครงการนำร่อง

หนึ่งไซต์ ขอบเขตตายตัว: การติดตั้ง การตั้งค่าตามข้อกำหนดของคุณ การอบรมหนึ่งครั้ง และช่วงเวลาสนับสนุน

เหมาะกับใคร

เมื่อ "ไม่มีการอัปโหลด" ยังไม่พอ

เหมาะเมื่อ

  • เครื่องทำงานไม่มีอินเทอร์เน็ต หรือไม่ได้รับอนุญาตให้โหลดซอฟต์แวร์จากอินเทอร์เน็ต
  • คุณต้องการเวอร์ชันเดียวที่ผ่านการตรวจสอบ (audit) แล้ว และไม่เปลี่ยนจนกว่าคุณจะตัดสินใจ
  • โมเดลของผู้รับจ้างต้องตรวจกับ IDS หรือ EIR ของคุณโดยไม่ผ่านบุคคลที่สาม
  • คุณต้องการมีคนให้โทรหาเมื่อระบบใช้งานไม่ได้

ไม่จำเป็นเมื่อ

  • นโยบายของคุณห้ามเพียงการอัปโหลดโมเดล ตัวตรวจสอบสาธารณะไม่อัปโหลดโมเดล
  • คุณมีบุคลากรที่โฮสต์เองได้ โค้ดใช้สัญญาอนุญาต MIT และมี Dockerfile: build image แล้วให้บริการได้เลย โครงการนำร่องเพิ่มการตั้งค่า การอบรม และการสนับสนุน ไม่ใช่ผลิตภัณฑ์อีกตัว

สิ่งที่ได้รับ

ติดตั้งอะไร และไม่ติดตั้งอะไร

รายละเอียด
ซอฟต์แวร์วิวเวอร์ กฎ 44 ข้อพร้อม Health Score, IDS 1.0, BCF 2.1 และ 3.0 เปิดหลายโมเดลพร้อมกัน การวัดและการตัด section เป็นเว็บแอปแบบ static ที่ nginx ให้บริการจาก container การตรวจทำงานในเบราว์เซอร์ของผู้ใช้แต่ละคน
เซิร์ฟเวอร์เครื่องใดก็ได้ที่รัน container ได้ ทำหน้าที่ส่งไฟล์เท่านั้นจึงใช้ทรัพยากรน้อย: งานทำโดยเครื่องทำงานของผู้ใช้
การเชื่อมต่อใน build นี้ไม่มีการเชื่อมต่อขาออกและไม่มีสถิติการใช้งาน
ใช้ออฟไลน์ไม่ได้บริบทแผนที่ 3D (ภูมิประเทศ อาคารจาก OpenStreetMap) และโมเดลตัวอย่างออนไลน์ เพราะต้องดาวน์โหลดจากอินเทอร์เน็ต
ข้อกำหนดของคุณไฟล์ IDS โปรไฟล์การตรวจสอบ และรูปแบบการตั้งชื่อของคุณ ถูกโหลดและทดสอบกับโมเดลของคุณเอง
การอัปเดตไฟล์ image ใหม่ ส่งมอบผ่านช่องทางที่คุณเลือก ไม่มีอะไรอัปเดตเอง
ฮาร์ดแวร์เซิร์ฟเวอร์หรือ virtual machine ของคุณเอง จัดหา gateway ที่ตั้งค่าไว้ล่วงหน้าให้ได้เมื่อร้องขอ

โครงการนำร่อง

โครงการนำร่องทำงานอย่างไร

  1. โทรคุยกำหนดขอบเขต

    กฎของเครือข่าย ขนาดโมเดล ข้อกำหนดของคุณ และใครจะเป็นผู้ใช้

  2. การติดตั้ง

    บนเซิร์ฟเวอร์ของคุณ พร้อมโหลดไฟล์ IDS และโปรไฟล์ของคุณ

  3. การอบรม

    หนึ่งครั้งกับ BIM coordinator ของคุณ โดยใช้โมเดลของคุณเอง

  4. การตัดสินใจ

    หลังช่วงเวลาสนับสนุน คุณตัดสินใจว่าจะขยายไปยังไซต์อื่นหรือไม่

FAQ

คำถามที่พบบ่อย

มีอะไรออกจากเครือข่ายของเราหรือไม่

ไม่มี container ส่งแอปพลิเคชันให้เบราว์เซอร์ของคุณและไม่เชื่อมต่อขาออก build นี้ไม่มีสถิติการใช้งาน โมเดลถูกอ่านในเบราว์เซอร์ของผู้ใช้แต่ละคนและไม่ถูกเก็บบนเซิร์ฟเวอร์

ต่างจากแอปสาธารณะอย่างไร

เป็นโปรแกรมเดียวกัน สิ่งที่ต่างคือที่ที่ให้บริการ เป็นเวอร์ชันตายตัว และฟีเจอร์ที่ต้องใช้อินเทอร์เน็ต (บริบทแผนที่และโมเดลตัวอย่างออนไลน์) ใช้ไม่ได้

เราโฮสต์เองโดยไม่ผ่านคุณได้หรือไม่

ได้ ซอร์สโค้ดเปิดเผยภายใต้สัญญาอนุญาต MIT และมี Dockerfile กับการตั้งค่า nginx โครงการนำร่องมีไว้สำหรับทีมที่ต้องการให้ตั้งค่า อธิบาย และสนับสนุนให้

โมเดลใหญ่ได้แค่ไหน

เท่ากับแอปสาธารณะ: ต่ำกว่า 2 GB ต่อไฟล์ ในทางปฏิบัติจำกัดด้วยหน่วยความจำของเครื่องทำงานแต่ละเครื่อง เพราะการตรวจทำงานในเบราว์เซอร์
