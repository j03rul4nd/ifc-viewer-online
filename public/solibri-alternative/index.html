GUID checks

Duplicate GlobalIds, invalid base64 format. Most common export error from Revit, ArchiCAD, Tekla. Auto-fixable with one click.

Spatial hierarchy

FAQ

Questions


Is IFC Viewer Online a good replacement for Solibri Anywhere?

For individual BIM Coordinators who need to check IFC models before delivery — yes. It runs 38 validation rules in your browser with zero setup, gives a Health Score from 0 to 100, and lets you fix GUID errors and export a corrected IFC without a server. It does not yet support IDS-based validation or multi-user cloud workflows, but for the core pre-delivery check workflow it is a practical, free, and private replacement.

What happened to Solibri Anywhere?

Solibri Anywhere, the free tier of Solibri Model Checker, was discontinued on April 13, 2026. Users who relied on it for basic IFC viewing and quality checking now need an alternative. The paid tiers of Solibri Model Checker remain available at €495–€2,772/year.

Does IFC Viewer Online work on Mac?

Yes. Unlike Solibri Anywhere (Windows-only desktop app), IFC Viewer Online works in any modern browser on Mac, Windows, and Linux. Chrome, Edge, Firefox, and Safari are all supported. No plugin, no installation required.

Can I use it with confidential models under NDA?

Yes. All processing happens in your browser via WebAssembly — no data is ever transmitted to any server. You can safely use it with confidential project models under NDA. There is no service agreement to review with your client.

Is there a file size limit?

There is no hard limit — the validator handles files up to ~2 GB. Performance depends on your device. Files under 200 MB load well on most modern hardware. Parsed geometry is cached in the browser's Origin Private File System (OPFS) so subsequent loads of the same file are instant.

Does it have BCF export like Solibri?

Yes. After running validation, you can export all issues as a BCF 2.1 file for coordination with Navisworks, BIMcollab, and other BCF-compatible tools. Individual issues can also be added to a BCF topic directly from the issue panel.
