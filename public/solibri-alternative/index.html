What gets checked

Rules span schema quality, spatial hierarchy, ISO 19650 compliance, LOD completeness, and coordination checks.

GUID checks

Duplicate GlobalIds, invalid base64 format. Most common export error from Revit, ArchiCAD, Tekla. Auto-fixable with one click.

Spatial hierarchy

IfcSite → IfcBuilding → IfcBuildingStorey chain. Orphan elements with no spatial containment. Missing project context.

Naming & ISO 19650

Empty Name / LongName attributes. Generic placeholders. Naming convention patterns configurable per project.

Property sets

Missing required Psets for walls, slabs, columns, beams. Empty or null property values that break downstream QTO.

LOD completeness

Verifies expected property sets are present at LOD 200 / 300 / 400 for common structural element classes.

Schema & geometry

IFC schema version compatibility, unit assignments, type assignments, material associations, degenerate geometry.

FAQ

Questions


Is IFC Viewer Online a good Solibri alternative?

For individual BIM Coordinators who need to check IFC models before delivery — yes. It runs 44 validation rules in your browser with zero setup, gives a Health Score from 0 to 100, and lets you fix GUID errors and export a corrected IFC without a server. It also supports full IDS 1.0 validation — load a buildingSMART .ids file and check your model against it locally. It does not aim to replace Solibri's enterprise rule authoring, COBie checking or full BCF lifecycle, but for the core pre-delivery check workflow it is a practical, free, and private option — and the two work well side by side.

Can it replace the Solibri IFC viewer for inspecting models?

Yes — for viewing and inspecting an IFC, it is a full replacement: WebGL 3D navigation, section planes, isolate/hide, a spatial tree, and click-to-inspect property sets, all in the browser. Drop a file and it loads in seconds with nothing uploaded. Solibri remains stronger for geometric (polygon-level) clash detection and very large federated models where desktop RAM is the limit.

Does IFC Viewer Online work on Mac?

Yes. Because it runs in the browser, IFC Viewer Online works on Mac, Windows, and Linux — Chrome, Edge, Firefox, and Safari are all supported. No plugin, no installation required, no operating-system restriction.

Can I use it with confidential models under NDA?

Yes. All processing happens in your browser via WebAssembly — no data is ever transmitted to any server. You can safely use it with confidential project models under NDA. There is no service agreement to review with your client.

Is there a file size limit?

There is no hard limit — the validator handles files up to ~2 GB. Performance depends on your device. Files under 200 MB load well on most modern hardware. Parsed geometry is cached in the browser's Origin Private File System (OPFS) so subsequent loads of the same file are instant.

Does it have BCF export like Solibri?

Yes. After running validation, you can export all issues as a BCF 2.1 file for coordination with Navisworks, BIMcollab, and other BCF-compatible tools. Individual issues can also be added to a BCF topic directly from the issue panel.
