Plugin WordPress

Disponibile Gratis

Cosa fa

Un blocco e uno shortcode [ifc_viewer] che mostrano un modello IFC 3D interattivo in articoli e pagine.

Per chi

Architetti, ingegneri e produttori che pubblicano progetti o prodotti su un sito WordPress.

Installazione
  1. In WordPress apri Plugin → Aggiungi nuovo.
  2. Cerca “Bimo IFC Viewer”, installalo e attivalo.
  3. Aggiungi il blocco IFC Viewer, o incolla [ifc_viewer model="…"], con un URL pubblico dell’IFC.
Limiti

L’IFC deve essere raggiungibile via URL (libreria media o link pubblico). I modelli molto grandi si caricano lentamente sul telefono.

Scarica da wordpress.org

App Shopify

In revisione

Cosa fa

Un modello IFC per prodotto o variante, una tabella di specifiche letta dal modello e download di file nella pagina prodotto.

Per chi

Produttori di prodotti per l’edilizia che vendono o presentano il catalogo su Shopify.

Installazione
  1. Installa l’app dallo Shopify App Store quando sarà approvata.
  2. Associa un file IFC a un prodotto o a una variante.
  3. Aggiungi il blocco del viewer al modello prodotto nell’editor del tema.
Limiti

L’app è stata inviata allo Shopify App Store ed è in revisione, quindi non si può ancora installare. Piani: Free, Starter e Business. Oggi puoi copiare le sezioni gratuite da GitHub.

SDK JavaScript

Disponibile Gratis

Cosa fa

Monta il viewer nella tua app web e carica i byte IFC dal tuo codice, con eventi e un’API per selezione, colori e camera.

Per chi

Sviluppatori di CDE, portali e strumenti interni.

Installazione
  1. Importa il modulo SDK da /sdk/ifc-viewer.es.js.
  2. Crea il viewer su un elemento della tua pagina.
  3. Passa i byte IFC dalla tua app con viewer.add().
Limiti

Funziona solo nel browser: serve una pagina che lo ospiti. L’SDK non salva i file per te.

Incorpora (iframe)

Disponibile Gratis

Cosa fa

Incolla un iframe per mostrare un modello in qualsiasi pagina, con la camera, i colori e i pannelli scelti nel generatore.

Per chi

Chiunque abbia un sito, un blog o un CMS e non voglia scrivere codice.

Installazione
  1. Apri il generatore di incorporamento.
  2. Incolla un URL pubblico dell’IFC e imposta la vista.
  3. Copia l’iframe nella tua pagina.
Limiti

L’URL del modello deve consentire richieste cross-origin (CORS). L’iframe richiede circa 400 px di altezza.

Server locale per strumenti desktop (MCP)

Disponibile Gratis

Cosa fa

Un server locale che consente ad app desktop ed editor di codice compatibili con Model Context Protocol di validare IFC, verificare IDS e aprire modelli in 3D.

Per chi

Coordinatori BIM e sviluppatori che lavorano con IFC da strumenti desktop.

Installazione
  1. Installa Node.js 18 o successivo.
  2. Aggiungi “npx -y ifc-viewer-mcp” come server nelle impostazioni MCP del tuo strumento.
  3. Riavvia lo strumento e indicagli un IFC sul tuo disco.
Limiti

Serve uno strumento desktop compatibile con MCP e Node.js. La validazione gira sul tuo computer; la vista 3D si apre nel browser.
