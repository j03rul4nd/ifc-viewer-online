Ambito

Che cosa copre questa verifica, e che cosa no

Controlla

  • Identificatori, struttura spaziale, piani, nomi, valori di proprietà, tipi e materiali: 44 regole, 25 attive per impostazione predefinita.
  • File IDS 1.0 con i loro sei facet.
  • Cinque profili di validazione integrati, oppure i tuoi schemi di denominazione e property set obbligatori.

Non controlla

  • I set di regole di Solibri. Un file .cset qui non si può caricare.
  • Hard clash tra discipline, regole di accessibilità o analisi degli spazi.
  • File da 2 GB in su.

Il tuo file

Che cosa succede al file

L’IFC viene letto da codice che gira nella scheda del tuo browser e non viene caricato. Il browser conserva una copia convertita della geometria nel suo spazio di archiviazione privato sul tuo computer (fino a 4 GB) per riaprirlo più in fretta; cancellando i dati del sito la rimuovi.

Le statistiche d’uso senza cookie registrano la dimensione del file e il numero di elementi, mai il contenuto, e si possono disattivare. Un link di condivisione, se ne crei uno, contiene il punteggio, il nome del file e fino a 50 problemi dentro l’URL.

FAQ

Domande

Che cos’è Solibri WebChecker?

Con le parole di Solibri, “a browser-based model validation service that runs Solibri's rules-based checking engine online”. Gli utenti caricano modelli IFC, eseguono il controllo Model Health o un set di regole personalizzato, ed esportano PDF o BCF (solibri.com/solutions/webchecker, letto il 2026-11-10).

Solibri WebChecker è gratuito?

No. È incluso in Solibri Advanced e Premium e non viene venduto separatamente. Ogni verifica consuma 50 token dalla dotazione annuale del piano o da pacchetti di token che partono da 250 € per 5.000 token (solibri.com/solutions/webchecker, letto il 2026-11-10).

WebChecker carica il mio modello?

Sì: Solibri lo descrive come un servizio in cui gli utenti caricano modelli IFC, con i dati conservati nell’UE o negli Stati Uniti e i risultati tenuti per 30 giorni (solibri.com/solutions/webchecker, letto il 2026-11-10). IFC Viewer Online invece legge il file nel tuo browser.

Posso eseguire qui i miei set di regole Solibri?

No. I set di regole Solibri (.cset) girano soltanto in Solibri. I requisiti che si possono scrivere come IDS 1.0 si possono verificare qui.

Quale dei due trova più problemi?

Cercano cose diverse. Il controllo Model Health di WebChecker include gli hard clash tra discipline, che questa pagina non fa. Questa pagina dà un punteggio e correzioni automatiche per identificatori e nomi. Per il coordinamento, usa Solibri.
