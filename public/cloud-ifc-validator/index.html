What the validator checks

Rules span schema quality, spatial hierarchy, ISO 19650 naming, property completeness, georeferencing and coordination — plus full IDS 1.0.

GUID integrity

Duplicate GlobalIds and invalid base64 format — the most common Revit / ArchiCAD / Tekla export error. Auto-fixable.

Spatial hierarchy

IfcSite → IfcBuilding → IfcBuildingStorey chain, plus orphan elements with no spatial containment.

Naming & ISO 19650

Empty Name / LongName attributes and generic placeholders that break downstream metadata.

Property sets

Missing or empty required Psets for walls, slabs, columns and beams that break quantity takeoff.

Georeferencing

Coordinate offsets > 10 km from origin — a classic federation error across discipline models.

IDS 1.0 compliance

Load a buildingSMART .ids requirements file and validate Entity, Attribute, Property, Classification, Material and PartOf facets.

FAQ

Questions


Is this a real cloud IFC validator?

It gives you everything people want from a cloud IFC validator — a URL you open in any browser, no install, instant results, a shareable report — but it processes the file on your own device instead of a remote server. The IFC is parsed in your browser via WebAssembly, so the model is never uploaded. Cloud-style convenience, without the data-handling risk.

Why validate IFC in the browser instead of a server-side cloud?

Server-side cloud validators require you to upload the model, which is often blocked by NDAs, client agreements, or public-sector data rules. Browser-based validation removes that blocker: no upload, no account, nothing to review with your client's data team — and it is instant, with no queue.

What does it check?

44 quality rules across GUID integrity, spatial hierarchy, orphan elements, naming (ISO 19650), property-set completeness, units, geometry validity, proxy overuse and coordinate offsets — plus a Health Score 0–100, and full buildingSMART IDS 1.0 against any .ids file you load.

Is it really free?

Yes — free for all use cases including commercial work, no account, no file-size paywall. The viewer and validator are open source under the MIT licence.

Can I share the validation results?

Yes. After validating, use Share Report to generate a URL that encodes the full Health Score and issue list. Your client opens it in any browser — the IFC file itself is never included in the link.
