为什么不会拖累您的页面
约 30 KB，分两步加载
3 KB 的加载器预留位置，页面不会跳动。27 KB 的引擎在地图接近屏幕时才加载。没有地图库，也没有瓦片服务器。
无需征求同意
没有 Cookie、分析或第三方请求。世界地图内置在文件中，访客 IP 不会发送给地图服务商。
可自由定制
在表单中设置颜色、字体、Logo 和语言。您的 CSS 可以设置 --tg-accent 等变量，并通过 ::part() 调整各部分。


常见问题
这是实时 GPS 跟踪器吗？
不是。它绘制您提供的数据：来自您系统的日期、进度或位置。它不连接承运商或船舶。路线是示意性的，不用于导航。
可以展示模拟货运吗？
可以，用于演示和销售页面。它们始终带有可见的“模拟数据”标签，以免被误认为真实货物。
如何保护货运数据隐私？
不要把数据粘贴到代码中。让组件指向您的服务器并使用单号查询，按您的规则每次只获取一个单号。
能在 SharePoint 中使用吗？
可以通过“嵌入” Web 部件以 iframe 方式使用，前提是网站所有者允许该域名。内容中的脚本不会运行。我们尚未在真实租户中测试。
能在淘宝上使用吗？
就我们能确认的情况，无法作为实时组件使用。您可以发布地图图片，并在自己的页面托管实时版本。
需要付费吗？
无需账号，也无需费用。它在访客的浏览器中运行，没有我们的服务器需要付费。
邮件套件免费吗？
不免费。网站组件免费；邮件套件和跟踪页面生成器属于 Pro 方案，目前尚未开售。
实时 3D 地图能在邮件里运行吗？
不能。邮件客户端不运行脚本。邮件中放图片或 GIF 和个人链接，交互地图在跟踪页面打开。
如何衡量带来的销售？
邮件平台统计链接点击。页面所有外链都带活动标签，您的商店分析可以归因销售。与收到普通邮件的对照组比较，才能衡量真实提升。
