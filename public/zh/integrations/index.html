WordPress 插件

可用 免费

功能

一个区块和一个 [ifc_viewer] 短代码，在文章和页面中显示可交互的 3D IFC 模型。

适用对象

在 WordPress 网站上发布项目或产品的建筑师、工程师和制造商。

安装
  1. 在 WordPress 中打开 插件 → 安装插件。
  2. 搜索 “Bimo IFC Viewer”，安装并启用。
  3. 添加 IFC Viewer 区块，或粘贴 [ifc_viewer model="…"]，并填入公开的 IFC 地址。
限制

IFC 必须能通过 URL 访问（媒体库或公开链接）。超大模型在手机上加载较慢。

JavaScript SDK

可用 免费

功能

把查看器挂载到您自己的 Web 应用中，从代码加载 IFC 字节，并提供选择、颜色和相机的事件与 API。

适用对象

CDE、门户和内部工具的开发者。

安装
  1. 从 /sdk/ifc-viewer.es.js 导入 SDK 模块。
  2. 在页面元素上创建查看器。
  3. 用 viewer.add() 从应用传入 IFC 字节。
限制

只在浏览器中运行：需要一个承载它的页面。SDK 不替您存储文件。

嵌入（iframe）

可用 免费

功能

粘贴一个 iframe，即可在任意页面显示模型，相机、颜色和面板可在嵌入生成器中设置。

适用对象

拥有网站、博客或 CMS 但不想写代码的人。

安装
  1. 打开嵌入生成器。
  2. 粘贴公开的 IFC 地址并设置视图。
  3. 把 iframe 复制到您的页面。
限制

模型地址必须允许跨域请求（CORS）。iframe 需要约 400 px 高度才好用。

桌面工具本地服务器（MCP）

可用 免费

功能

一个本地服务器，让支持 Model Context Protocol 的桌面应用和代码编辑器验证 IFC、检查 IDS 并以 3D 打开模型。

适用对象

在桌面工具中处理 IFC 文件的 BIM 协调员和开发者。

安装
  1. 安装 Node.js 18 或更新版本。
  2. 在工具的 MCP 设置中添加服务器 “npx -y ifc-viewer-mcp”。
  3. 重启工具，并指向磁盘上的 IFC 文件。
限制

需要支持 MCP 的桌面工具和 Node.js。验证在您的电脑上运行；3D 视图在浏览器中打开。
