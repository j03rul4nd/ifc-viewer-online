# Port de Barcelona IFC objects

Source: [Biblioteca de Objetos IFC del Planol del Port de Barcelona](https://serveis.portdebarcelona.cat/cataleg_bim_planol/), © Port de Barcelona, licensed under [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/).

Changes: the IFC files are unmodified copies, one level of detail per object, renamed only where the source grouped them. Thumbnails are reduced versions of the source images, converted to WebP.

Regenerate with `python scripts/port-library/mirror.py`.
