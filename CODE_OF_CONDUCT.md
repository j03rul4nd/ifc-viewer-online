# Code of Conduct

This project follows the [Contributor Covenant 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful, assume good intent, keep discussion about the work, and no harassment of any kind.

Report unacceptable behaviour privately to **privacy@ifcvieweronline.eu**. Reports are handled confidentially, and the maintainer may remove comments, issues or contributors that break these rules.
